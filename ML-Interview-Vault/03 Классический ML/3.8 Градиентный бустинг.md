# 3.8 Градиентный бустинг ⭐⭐⭐ (самое важное для табличных данных и Сбера)

## Идея
Строим ансамбль **последовательно**: каждая новая модель исправляет ошибки текущего ансамбля.
$$F_M(x) = F_0(x) + \eta\sum_{m=1}^M h_m(x)$$
$h_m$ — неглубокие деревья (depth 3–8): **высокий bias, низкая variance** → бустинг снижает bias.

## AdaBoost (исторически первый)
Перевзвешивание объектов: ошибочно классифицированные получают **больший вес**, следующий классификатор фокусируется на них. Вес модели $\alpha_m = \frac12\ln\frac{1-err_m}{err_m}$. Эквивалентен минимизации **экспоненциального лосса**. Чувствителен к выбросам.

## Gradient Boosting (Friedman) ⭐
Бустинг = **градиентный спуск в пространстве функций**.

На шаге $m$:
1. Считаем **антиградиент** лосса по предсказаниям (псевдо-остатки):
$$r_i = -\left.\frac{\partial L(y_i, F)}{\partial F}\right|_{F=F_{m-1}(x_i)}$$
2. Обучаем дерево $h_m$ предсказывать $r_i$ (регрессия, MSE).
3. (Оптимизируем значения в листьях под исходный лосс.)
4. $F_m = F_{m-1} + \eta\, h_m$.

| Лосс | Антиградиент $r_i$ |
|---|---|
| MSE $\frac12(y-F)^2$ | $y - F$ — **обычные остатки** |
| MAE | $\text{sign}(y-F)$ |
| Log-loss (логит $F$) | $y - \sigma(F)$ |

```
 Шаг 0: F₀ = mean(y)            ─────────────  (константа)
 Шаг 1: дерево на остатках y−F₀  ‾‾‾‾\___/‾‾‾  грубо
 Шаг 2: дерево на новых остатках ‾‾\_/‾\__/‾‾  точнее
 ...
 Шаг M:                          ∿∿∿∿∿∿∿∿∿∿∿  (риск переобучения!)
```

## Ключевые гиперпараметры
| Параметр | Эффект |
|---|---|
| `learning_rate` (η, shrinkage) | меньше → нужно больше деревьев, но лучше обобщение. Типично 0.01–0.1 |
| `n_estimators` | **может переобучить** → early stopping по валидации |
| `max_depth` / `num_leaves` | сложность взаимодействий |
| `subsample` | доля объектов на дерево (**Stochastic GB**) |
| `colsample_bytree` | доля признаков |
| `min_child_weight` / `min_data_in_leaf` | |
| `reg_lambda`, `reg_alpha` | L2/L1 на значения листьев |

Правило: η↓ ⇔ n_estimators↑.

## XGBoost — что нового
- Разложение лосса до **второго порядка** (градиент $g_i$ и гессиан $h_i$, как метод Ньютона).
- Регуляризация в целевой функции: $\Omega(f) = \gamma T + \frac12\lambda\|w\|^2$ ($T$ — число листьев).
- Оптимальное значение в листе: $w_j^* = -\frac{G_j}{H_j+\lambda}$.
- Gain разбиения: $\frac12\left[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma$.
- Sparsity-aware: обработка пропусков (учится направлению по умолчанию).
- Level-wise рост, параллелизация по признакам, гистограммы, GPU.

## LightGBM — что нового
- **Leaf-wise** (best-first) рост дерева — быстрее снижает лосс, но риск переобучения → `num_leaves`, `max_depth`.
- **Гистограммный** алгоритм (биннинг признаков).
- **GOSS** (Gradient-based One-Side Sampling): оставляем объекты с большими градиентами + случайную часть малых.
- **EFB** (Exclusive Feature Bundling): склеивает взаимоисключающие разреженные признаки.
- Нативные категориальные признаки.
→ Самый **быстрый** на больших данных.

```
 Level-wise (XGBoost)        Leaf-wise (LightGBM)
        ●                          ●
      /   \                      /   \
     ●     ●                    ●     ○
    / \   / \                  / \
   ○   ○ ○   ○                ●   ○
                             / \
                            ○   ○
```

## CatBoost (Яндекс) — что нового
- **Ordered Target Statistics** для категориальных признаков — target encoding без утечки (по случайной перестановке, используя только «прошлые» объекты).
- **Ordered boosting** — борьба с prediction shift (смещением градиентов).
- **Симметричные (oblivious) деревья**: на одном уровне одно и то же условие → быстрый инференс, регуляризация.
- Комбинации категориальных признаков автоматически.
→ Лучший «из коробки», особенно с **большим числом категориальных** признаков.

## Сравнение
| | XGBoost | LightGBM | CatBoost |
|---|---|---|---|
| Рост дерева | level-wise | leaf-wise | symmetric |
| Скорость обучения | средне | 🚀 быстро | медленнее (CPU), быстрый GPU |
| Категории | one-hot/нативно (новые версии) | нативно | ⭐ лучше всех |
| Дефолтное качество | хорошо | хорошо | ⭐ лучше без тюнинга |
| Инференс | | | 🚀 быстрый |

## Bagging vs Boosting
| | Бэггинг / RF | Бустинг |
|---|---|---|
| Обучение | параллельно | последовательно |
| Базовые модели | глубокие деревья | неглубокие деревья |
| Снижает | variance | bias (и variance с регуляризацией) |
| Переобучение от числа моделей | нет | **да** |
| Чувствительность к шуму | низкая | выше |
| Тюнинг | мало | много |
| Качество на таблицах | хорошо | ⭐ SOTA |

## Почему бустинг > нейросети на таблицах
Гетерогенные признаки, разные масштабы, неинформативные признаки, нерегулярные зависимости (деревья хорошо режут «ступеньками»), мало данных. Нейросети (TabNet, FT-Transformer) иногда догоняют, но бустинг проще и стабильнее.
