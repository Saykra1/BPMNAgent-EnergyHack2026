# 3.3 k ближайших соседей (kNN)

## Идея
«Скажи мне, кто твой друг». Классифицируем объект по **большинству среди k ближайших** соседей (регрессия — среднее).

```
        ○       ○
     ○     ╭─────────╮
        ●  │  ○   ●  │      k=3: ●●○ → ●
     ●     │    ✖    │      k=7: ●●●○○○○ → ○
        ●  │ ●    ○  │      (ответ зависит от k!)
           ╰─────────╯
     ●   ○       ○
```

## Ключевые моменты
- **Ленивое обучение** (lazy): обучение = запомнить выборку, $O(1)$. Предсказание $O(nd)$ — дорого.
- **Непараметрическая** модель.
- **Метрики**: евклидова, манхэттенская, косинусная, Минковского $(\sum|x_i-y_i|^p)^{1/p}$.
- **Взвешенный kNN**: вес соседа $\propto 1/d$ или ядро.
- **Масштабирование признаков обязательно!**
- **Выбор k**: малое k → переобучение (высокая variance), большое k → недообучение (высокий bias). Подбирать CV; для бинарной — нечётное k.

## Ускорение
- **KD-tree**, **Ball-tree** — точный поиск, хорошо при малом $d$ (< ~20).
- **ANN (approximate nearest neighbors)**: **HNSW** (графы), **IVF** (кластеры), **PQ** (product quantization), LSH. Библиотеки: FAISS, Annoy, ScaNN. → основа **векторных БД** в [[5.15 RAG и агенты|RAG]].

## Проклятие размерности
В высокой размерности все точки почти равноудалены → «ближайший сосед» теряет смысл. → [[2.7 Предобработка и Feature Engineering#Проклятие размерности]]
