# 3.11 Поиск аномалий (Anomaly / Outlier Detection)

Применения: **антифрод**, мониторинг транзакций, кибербезопасность, мониторинг оборудования, качество данных.

## Постановки
- **Supervised** — есть метки фрода → классификация с [[3.14 Дисбаланс классов|дисбалансом]].
- **Semi-supervised (novelty detection)** — учимся только на «нормальных».
- **Unsupervised (outlier detection)** — меток нет.

## Методы
| Метод | Идея |
|---|---|
| **Статистические**: z-score, IQR, Граббс | далеко от центра распределения |
| **Mahalanobis distance** | $\sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)}$ — учитывает корреляции |
| **Isolation Forest** ⭐ | аномалии **легко изолировать**: случайные деревья со случайными разбиениями; аномалии оказываются на **малой глубине** |
| **LOF** (Local Outlier Factor) | локальная плотность точки ниже, чем у её соседей |
| **One-Class SVM** | граница вокруг нормальных данных |
| **DBSCAN** | noise-точки = аномалии |
| **Автоэнкодер** | большая **ошибка реконструкции** → аномалия |
| **Elliptic Envelope** | робастная оценка гауссианы |
| Временные ряды | отклонение от прогноза, STL-остатки |

```
 Isolation Forest:
   нормальная точка: нужно много разрезов     аномалия: 1–2 разреза
   ┌──┬──┬───┐                                ┌─────────┬──┐
   │··│·•│···│                                │ ······· │ ✖│
   ├──┼──┼───┤                                │ ······· │  │
   │··│··│···│                                └─────────┴──┘
   └──┴──┴───┘
   score = 2^(−E[h(x)]/c(n))  — близко к 1 → аномалия
```

## Оценка
PR-AUC, Precision@k (сколько настоящего фрода в топ-k алертов — ограничена ёмкость аналитиков), recall при фиксированном FPR.
