# 3.10 Понижение размерности

Зачем: визуализация, борьба с проклятием размерности, сжатие, удаление шума и мультиколлинеарности, ускорение.

## PCA — метод главных компонент ⭐
Ищем ортогональные направления **максимальной дисперсии**.
```
  x2│      ·  ·  ↗ PC1 (макс. дисперсия)
    │    · ·· ·↗
    │  ·  ··↗ ·
    │ · ·↗ ·  ↖ PC2 (ортогонально, остаток)
    │  ↗ ·
    └─────────────── x1
```
**Алгоритм:**
1. Центрировать (и обычно стандартизовать) $X$.
2. Ковариационная матрица $C = \frac1{n-1}X^\top X$.
3. Собственные векторы $C$ = главные компоненты, собственные значения = дисперсия вдоль них.
4. Проекция на первые $k$: $Z = XV_k$.

**Через SVD** (так делают на практике, численно стабильнее): $X = U\Sigma V^\top$; компоненты = столбцы $V$, дисперсии $=\frac{\sigma_i^2}{n-1}$.

- **Explained variance ratio** $\frac{\lambda_i}{\sum\lambda_j}$ → выбираем $k$, чтобы объяснить 90–95% (scree plot).
- Эквивалентно: минимизация ошибки реконструкции $\|X - XV_kV_k^\top\|^2$.
- ❌ Только **линейные** зависимости; компоненты трудно интерпретировать; чувствителен к масштабу.
- Варианты: Kernel PCA (нелинейный), Incremental PCA, Sparse PCA, Randomized SVD.

## Другие линейные
- **LDA (Linear Discriminant Analysis)** — supervised: максимизирует разделимость классов (межклассовая / внутриклассовая дисперсия). Макс. $K-1$ компонент.
- **Truncated SVD (LSA)** — для разреженных матриц (TF-IDF), без центрирования.
- **NMF** — неотрицательная факторизация (интерпретируемые «части», темы).
- **ICA** — независимые компоненты (разделение сигналов, «cocktail party»).

## Нелинейные (manifold learning) — в основном для визуализации
| Метод | Суть | Особенности |
|---|---|---|
| **t-SNE** | сохраняет **локальные** соседства: $p_{ij}$ (гауссиана) в исходном → $q_{ij}$ (t-распределение Стьюдента, тяжёлые хвосты) в 2D, минимизирует KL | только визуализация; **расстояния между кластерами и размеры кластеров ничего не значат**; perplexity; медленно; не transform новых точек |
| **UMAP** | граф соседей + оптимизация | быстрее t-SNE, лучше сохраняет глобальную структуру, есть transform |
| **Isomap, LLE** | геодезические расстояния / локальная линейность | |
| **Автоэнкодеры** | нейросетевое нелинейное сжатие | → [[4.12 Генеративные модели]] |
