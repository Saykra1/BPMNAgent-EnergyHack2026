# 3.5 SVM — метод опорных векторов

## Идея: максимальный зазор (margin)
Из всех разделяющих гиперплоскостей выбираем ту, у которой **максимальное расстояние до ближайших точек** обоих классов.

```
        ○            ╲   ╲   ╲
     ○     ○          ╲   ╲   ╲
        ◉ ←опорный     ╲   ╲   ╲      ●
     ○        ○         ╲   ╲   ◉ ←опорный
                    ◉    ╲   ╲   ╲  ●
                          ╲   ╲   ╲      ●
                         wᵀx+b=-1  │  wᵀx+b=+1
                               wᵀx+b=0
                         |←── 2/‖w‖ ──→|  margin
```
Ширина зазора = $\frac{2}{\|w\|}$ → максимизировать зазор = **минимизировать $\|w\|^2$**.

## Hard margin (разделимые данные)
$$\min_{w,b}\frac12\|w\|^2 \quad\text{s.t. } y_i(w^\top x_i + b)\ge1$$

## Soft margin (реальные данные)
$$\min\frac12\|w\|^2 + C\sum_i\xi_i,\quad y_i(w^\top x_i+b)\ge1-\xi_i,\ \xi_i\ge0$$
Эквивалентно безусловной задаче с **hinge loss**:
$$\min\ \frac12\|w\|^2 + C\sum_i\max(0,\,1-y_i(w^\top x_i+b))$$
- $C$ большое → меньше ошибок на train, узкий зазор → переобучение.
- $C$ маленькое → широкий зазор, больше нарушений → сильнее регуляризация.

## Опорные векторы
Решение зависит **только** от точек на границе зазора или внутри него ($\alpha_i>0$ в двойственной задаче, KKT). Остальные точки можно удалить — ответ не изменится.

## Двойственная задача и Kernel Trick ⭐
$$\max_\alpha \sum\alpha_i - \frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\,\langle x_i,x_j\rangle,\quad 0\le\alpha_i\le C,\ \sum\alpha_iy_i=0$$
Данные входят **только через скалярные произведения** → заменяем $\langle x_i,x_j\rangle$ на **ядро** $K(x_i,x_j) = \langle\varphi(x_i),\varphi(x_j)\rangle$ — неявное отображение в пространство высокой (даже бесконечной) размерности **без явного вычисления $\varphi$**.

```
 1D, неразделимо:  ●●○○○○●●        φ(x) = (x, x²)       ● ●       ● ●
                                    ──────────→              ○ ○ ○ ○
                                                        ────────────── ← разделимо!
```

| Ядро | Формула | |
|---|---|---|
| Линейное | $x^\top z$ | много признаков (тексты) |
| Полиномиальное | $(\gamma x^\top z + r)^p$ | |
| **RBF (Гауссово)** | $\exp(-\gamma\|x-z\|^2)$ | дефолт; $\gamma$↑ → сложнее граница → переобучение |
| Сигмоидное | $\tanh(\gamma x^\top z + r)$ | |
Условие Мерсера: матрица Грама PSD.

## Плюсы / минусы
✅ Хорош при $d\gg n$, выпуклая задача (глобальный оптимум), ядра для нелинейности, устойчив (зависит лишь от опорных векторов).
❌ $O(n^2)$–$O(n^3)$ — плохо на больших $n$; нет вероятностей «из коробки» (Platt scaling); чувствителен к масштабу; подбор $C,\gamma$.

## Варианты
- **SVR** — регрессия с ε-нечувствительным лоссом (ошибки внутри «трубки» ε не штрафуются).
- **One-Class SVM** — [[3.11 Поиск аномалий]].
