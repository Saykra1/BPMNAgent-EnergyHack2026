# 3.9 Кластеризация

Задача: разбить объекты на группы похожих **без разметки**. Пример: сегментация клиентов банка.

## K-Means ⭐
1. Случайно выбрать $k$ центроидов (лучше **k-means++**: следующий центр выбирается с вероятностью $\propto d^2$ до ближайшего).
2. **E-шаг**: отнести каждую точку к ближайшему центроиду.
3. **M-шаг**: пересчитать центроиды как средние.
4. Повторять до сходимости.

Минимизирует **inertia** (WCSS): $\sum_k\sum_{x\in C_k}\|x-\mu_k\|^2$. Сходится всегда, но в **локальный** минимум → несколько перезапусков (`n_init`).

```
 Итерация 1          Итерация 3 (сошлось)
  ○ ○  ✚   ● ●        ○ ○       ● ●
 ○ ○ ○    ● ●        ○ ✚ ○     ● ✚ ●
     ✚ ●  ●            ○        ● ●
```
❌ Нужно знать $k$; только **выпуклые сферические** кластеры одинакового размера; чувствителен к выбросам и масштабу. Сложность $O(nkdI)$.
**Выбор k**: метод локтя (elbow), **silhouette**, gap statistic, бизнес-смысл.
Варианты: Mini-batch K-Means, K-Medoids (PAM, робастен), K-Modes (категории).

## DBSCAN ⭐
Кластеры = **области высокой плотности**. Параметры: `eps` (радиус), `min_samples`.
- **Core**-точка: ≥ min_samples соседей в радиусе eps.
- **Border**: в окрестности core, но сама не core.
- **Noise**: остальные → **выбросы**!
```
   ●●●●●            ○ ← noise
  ●●●●●●●     ●●●●●●●●●●●
   ●●●●●     ●●●●      ●●●●   ← кластер произвольной формы (полумесяц)
```
✅ Не нужно k, **произвольная форма**, находит выбросы. ❌ Разная плотность кластеров, выбор eps (k-distance plot), высокая размерность. Улучшение: **HDBSCAN** (иерархический, без eps), OPTICS.

## Иерархическая (агломеративная)
Каждая точка — кластер, последовательно сливаем ближайшие. Результат — **дендрограмма**, режем на нужном уровне.
```
        ┌────┴────┐
     ┌──┴──┐      │
   ┌─┴─┐   │    ┌─┴─┐
   A   B   C    D   E
```
Linkage: single (min — «цепочки»), complete (max), average, **Ward** (минимальный прирост дисперсии — дефолт). $O(n^2)$ памяти.

## GMM — смесь гауссиан
$p(x) = \sum_k\pi_k\mathcal N(x|\mu_k,\Sigma_k)$, обучение — **EM-алгоритм**:
- E: апостериорные вероятности принадлежности $\gamma_{ik}$ (мягкая кластеризация),
- M: пересчёт $\pi,\mu,\Sigma$.
K-Means = частный случай GMM (равные сферические ковариации, жёсткое назначение). Выбор k — BIC/AIC.

## Другие
- **Spectral clustering** — по собственным векторам лапласиана графа сходства (невыпуклые кластеры).
- **Mean Shift** — поиск мод плотности.
- **Affinity Propagation**, **BIRCH** (большие данные).

## Метрики качества
| Без разметки | С разметкой |
|---|---|
| **Silhouette** $s = \frac{b-a}{\max(a,b)}\in[-1,1]$ ($a$ — среднее расстояние внутри кластера, $b$ — до ближайшего чужого) | ARI (Adjusted Rand Index) |
| Davies–Bouldin (меньше — лучше) | NMI / AMI |
| Calinski–Harabasz (больше — лучше) | Homogeneity, completeness, V-measure |
