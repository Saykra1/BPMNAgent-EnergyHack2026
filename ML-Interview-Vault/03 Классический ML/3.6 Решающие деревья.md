# 3.6 Решающие деревья ⭐⭐⭐

## Идея
Последовательность вопросов «признак ≤ порог?». Каждый лист — ответ (класс / среднее значение).

```
                 [доход ≤ 50k?]
                 /            \
              да               нет
              /                  \
     [просрочки > 0?]        [возраст ≤ 25?]
       /        \              /         \
   🔴 дефолт  🟢 ок       🟡 50/50     🟢 ок
```
Пространство признаков режется **осепараллельными** прямоугольниками:
```
 x2│ 🔴🔴 │ 🟢🟢🟢
   │ 🔴🔴 │ 🟢🟢🟢
   │──────┼────────
   │ 🟢🟢 │ 🟢🔴🟢
   └──────┴──────── x1
```

## Построение (жадный алгоритм CART)
В каждом узле перебираем все признаки и все пороги, выбираем разбиение с максимальным **приростом информации (Information Gain)**:
$$IG = H(\text{parent}) - \frac{N_L}{N}H(L) - \frac{N_R}{N}H(R)$$
Рекурсивно, пока не сработает критерий остановки.

## Критерии неоднородности (impurity) $H$
| Задача | Критерий | Формула |
|---|---|---|
| Классификация | **Gini** | $1 - \sum_k p_k^2$ |
| Классификация | **Энтропия** | $-\sum_k p_k\log_2 p_k$ |
| Классификация | Misclassification | $1-\max_k p_k$ (плохо для построения) |
| Регрессия | **MSE (дисперсия)** | $\frac1N\sum(y_i-\bar y)^2$ → лист = среднее |
| Регрессия | MAE | → лист = медиана |

```
 impurity (2 класса)
 1.0┤        ___         энтропия (max=1)
    │     _-‾   ‾-_
 0.5┤   /  _-‾‾‾-_ \     Gini (max=0.5)
    │  / /         \ \
  0 ┤_/_/___________\_\_
    0       0.5       1  → p
```
Gini и энтропия дают почти одинаковые деревья; Gini быстрее (нет логарифма).

## Регуляризация (борьба с переобучением)
Дерево без ограничений **запоминает выборку** (каждый объект в своём листе) → огромная variance.
- **Pre-pruning**: `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_leaf_nodes`, `min_impurity_decrease`.
- **Post-pruning**: cost-complexity pruning ($R_\alpha(T) = R(T) + \alpha|T|$, `ccp_alpha`).

## Свойства
✅ Интерпретируемость, нелинейность, **не нужно масштабирование**, работа с категориями и пропусками, взаимодействия признаков «бесплатно», быстрый инференс.
❌ **Высокая variance** (нестабильность: изменили пару объектов — другое дерево), ступенчатая аппроксимация, **не экстраполирует** (за пределами train — константа), жадность (не глобальный оптимум).

## Сложность
Обучение $O(n\,d\log n)$ (сортировка) или $O(n\,d)$ на гистограммах; предсказание $O(\text{depth})$.

## Важность признаков
- **MDI (Gini importance)**: суммарное уменьшение impurity по всем разбиениям признака. Смещена к признакам с большим числом уникальных значений.
- **Permutation importance**, **SHAP** → [[3.15 Интерпретируемость моделей]].

## Алгоритмы
ID3 (энтропия, категориальные), C4.5 (gain ratio, пропуски), **CART** (бинарные деревья, Gini/MSE — sklearn).
