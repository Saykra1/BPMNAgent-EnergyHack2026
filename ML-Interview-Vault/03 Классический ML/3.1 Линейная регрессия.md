# 3.1 Линейная регрессия

## Модель
$$\hat y = w_0 + w_1x_1 + \dots + w_dx_d = w^\top x \quad(\text{добавляем } x_0 = 1)$$

```
  y │        ●
    │     ●   ╱●
    │   ●  ╱  ●       ← прямая минимизирует сумму
    │  ● ╱ ●             квадратов вертикальных
    │  ╱●                отрезков (остатков)
    │╱ ●
    └──────────── x
```

## Обучение: МНК (OLS)
$$L(w) = \|Xw - y\|^2 \;\Rightarrow\; \nabla_w L = 2X^\top(Xw - y) = 0$$
$$\boxed{w^* = (X^\top X)^{-1}X^\top y}$$ — **нормальное уравнение**.

- Сложность: $O(nd^2 + d^3)$ → при большом $d$ используют **градиентный спуск**: $w \leftarrow w - \eta\cdot\frac2n X^\top(Xw-y)$.
- Геометрически: $\hat y = Xw^*$ — **ортогональная проекция** $y$ на пространство столбцов $X$.
- Вероятностно: MLE при гауссовом шуме ([[1.4 Статистика и MLE]]).

## Ridge / Lasso
- Ridge: $w = (X^\top X + \lambda I)^{-1}X^\top y$
- Lasso: аналитического решения нет, координатный спуск.
→ [[2.3 Регуляризация]]

## Предположения классической линейной регрессии (Гаусс–Марков)
1. **Линейность** зависимости.
2. **Независимость** ошибок.
3. **Гомоскедастичность** — постоянная дисперсия ошибок.
4. Отсутствие **мультиколлинеарности**.
5. (для доверительных интервалов) **Нормальность** ошибок.
При 1–4 OLS — **BLUE** (лучшая линейная несмещённая оценка).

## Проблемы и решения
| Проблема | Симптом | Решение |
|---|---|---|
| Нелинейность | паттерн в остатках | полиномиальные признаки, сплайны, логарифмы, другая модель |
| Мультиколлинеарность | большие, нестабильные веса, VIF>10 | Ridge, удалить признаки, PCA |
| Выбросы | | Huber, RANSAC, клиппинг |
| Гетероскедастичность | «воронка» в остатках | log(y), WLS, робастные ошибки |
| Разный масштаб | GD плохо сходится | стандартизация |

## Интерпретация
$w_j$ — изменение $\hat y$ при росте $x_j$ на 1 **при прочих равных**. Сравнивать веса можно только при стандартизованных признаках. Значимость — t-статистика, p-value (statsmodels).

## Полиномиальная регрессия
Линейная по **параметрам**, а не по признакам: $\hat y = w_0 + w_1x + w_2x^2 + \dots$ — всё ещё линейная регрессия. Степень ↑ → переобучение.

## Обобщённые линейные модели (GLM)
$g(\mathbb E[y]) = w^\top x$: логистическая (logit), Пуассоновская (log), Гамма.
