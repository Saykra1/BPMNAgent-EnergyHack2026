# 3.15 Интерпретируемость (XAI)

Важно в банке: регулятор, объяснение отказа клиенту, поиск утечек, доверие бизнеса.

## Глобальная vs локальная
- **Глобальная** — какие признаки важны для модели в целом.
- **Локальная** — почему **этому** клиенту отказали.

## Методы
| Метод | Тип | Суть |
|---|---|---|
| Веса линейной модели | глоб. | при стандартизованных признаках |
| **MDI (Gini importance)** | глоб. | смещён к высококардинальным признакам |
| **Permutation importance** | глоб. | перемешать признак на валидации → насколько упала метрика; модель-агностичный; проблема с коррелированными признаками |
| **PDP** (Partial Dependence) | глоб. | средний прогноз как функция признака |
| **ICE** | лок. | PDP для каждого объекта |
| **LIME** | лок. | локальная линейная аппроксимация вокруг объекта на возмущённых сэмплах |
| **SHAP** ⭐ | лок.+глоб. | значения Шепли из теории игр |

## SHAP ⭐
Вклад признака $j$ = среднее его **маргинального вклада** по всем подмножествам признаков:
$$\phi_j = \sum_{S\subseteq F\setminus\{j\}}\frac{|S|!(|F|-|S|-1)!}{|F|!}\big[f(S\cup\{j\}) - f(S)\big]$$
Свойства: **аддитивность** $f(x) = \phi_0 + \sum_j\phi_j$ (база + вклады), симметричность, нулевой игрок, согласованность.
- **TreeSHAP** — точный и быстрый для деревьев ($O(TLD^2)$).
- KernelSHAP — модель-агностичный (медленный), DeepSHAP — нейросети.
- Графики: waterfall (один объект), beeswarm/summary (глобально), dependence plot.

```
 Прогноз дефолта для клиента:   база 0.05
   + просрочки=3        ████████  +0.12
   + доход=низкий       ████      +0.06
   − стаж=10 лет      ███         −0.04
   = 0.19
```

## Для нейросетей
Saliency maps, Integrated Gradients, Grad-CAM (CNN), attention maps (осторожно: attention ≠ объяснение).
