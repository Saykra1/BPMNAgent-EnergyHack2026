# 3.13 Временные ряды

## Компоненты
$$y_t = \text{Тренд}_t + \text{Сезонность}_t + \text{Остаток}_t \quad(\text{аддитивная; или мультипликативная } \times)$$
```
 тренд ↗  +  сезонность ∿∿∿  +  шум ·.·.  =  ряд ↗∿∿
```
Декомпозиция: STL, seasonal_decompose.

## Стационарность
Ряд стационарен, если среднее, дисперсия и автоковариация не зависят от времени.
- Проверка: тест **Дики–Фуллера (ADF)**: $H_0$ — есть единичный корень (нестационарен); KPSS (наоборот).
- Приведение: **дифференцирование** $y_t - y_{t-1}$, сезонное дифференцирование $y_t - y_{t-s}$, логарифм / Box-Cox (стабилизация дисперсии).
- **ACF** (автокорреляция) и **PACF** (частичная) — выбор порядков ARIMA.

## Классические модели
| Модель | Суть |
|---|---|
| Наивные бейзлайны | $\hat y_{t+1}=y_t$; сезонный naive $\hat y_{t+s}=y_t$ — **всегда сравнивай с ними!** |
| Скользящее среднее | |
| **Экспоненциальное сглаживание** | SES → Holt (тренд) → **Holt-Winters** (тренд+сезонность), ETS |
| **AR(p)** | $y_t = c + \sum_{i=1}^p\phi_iy_{t-i} + \varepsilon_t$ (порядок по PACF) |
| **MA(q)** | $y_t = \mu + \varepsilon_t + \sum\theta_i\varepsilon_{t-i}$ (порядок по ACF) |
| **ARIMA(p,d,q)** | AR + d дифференцирований + MA |
| **SARIMA / SARIMAX** | + сезонность + экзогенные переменные |
| **Prophet** | тренд + сезонности Фурье + праздники |
| VAR | многомерные ряды |

## ML-подход (чаще всего в индустрии)
Сводим к регрессии с признаками:
- **Лаги**: $y_{t-1}, y_{t-7}, y_{t-364}$
- **Скользящие статистики** (rolling mean/std/min/max) — **сдвинутые**, чтобы не было утечки!
- Календарь: день недели, месяц, праздники, sin/cos.
- Экзогенные: цены, промо, погода.
→ **LightGBM/CatBoost**. Проблема: деревья **не экстраполируют тренд** → прогнозировать разности / нормировать на тренд.

Стратегии многошагового прогноза: **рекурсивная** (прогноз как вход), **прямая** (отдельная модель на каждый горизонт), MIMO.

## DL-модели
RNN/LSTM, **N-BEATS**, **TFT** (Temporal Fusion Transformer), **PatchTST**, DeepAR (вероятностный), foundation-модели (TimesFM, Chronos).

## Валидация
**Только по времени!** TimeSeriesSplit / expanding или sliding window, backtesting. → [[2.4 Валидация и подбор гиперпараметров]]
Метрики: MAE, RMSE, **MAPE/SMAPE/WAPE**, MASE (относительно наивного прогноза).
