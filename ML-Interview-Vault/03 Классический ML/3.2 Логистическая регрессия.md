# 3.2 Логистическая регрессия ⭐⭐⭐

> Несмотря на название — это **классификация**. Базовая модель банковского скоринга.

## Модель
$$p(y=1|x) = \sigma(w^\top x) = \frac{1}{1+e^{-w^\top x}}$$

```
 σ(z)
 1 ┤                 ___________
   │              _-‾
0.5┤ - - - - - - ●  ← z = 0 — граница решений
   │          _-
 0 ┤________-‾
   └──────────┼────────────── z = wᵀx
             0
```
- $w^\top x$ — **логит** (log-odds): $\log\frac{p}{1-p} = w^\top x$.
- Граница решений $w^\top x = 0$ — **гиперплоскость** (линейный классификатор).
- Интерпретация: рост $x_j$ на 1 умножает **шансы (odds)** на $e^{w_j}$.

## Обучение: log-loss (MLE для Бернулли)
$$L(w) = -\frac1n\sum_i\big[y_i\log p_i + (1-y_i)\log(1-p_i)\big]$$
$$\nabla_w L = \frac1n X^\top(p - y)$$ ← тот же вид, что у линрег!
- **Выпуклая** функция → единственный глобальный минимум.
- Аналитического решения нет → GD, Newton (IRLS), L-BFGS.
- С метками $y\in\{-1,+1\}$: $L = \sum\log(1+e^{-y_i w^\top x_i})$ — логистический лосс от отступа.

> [!warning] Линейно разделимые данные
> Без регуляризации веса → ∞ (сигмоида становится ступенькой, лосс → 0). Поэтому всегда L2 (в sklearn по умолчанию `C=1.0`, где $C = 1/\lambda$).

## Многоклассовая
- **Softmax (multinomial) regression**: $p_k = \frac{e^{w_k^\top x}}{\sum_j e^{w_j^\top x}}$, лосс — cross-entropy.
- **One-vs-Rest**: K бинарных классификаторов.
- **One-vs-One**: $K(K-1)/2$ классификаторов (так делает SVM).

## Нелинейность
Сама по себе граница линейна. Нелинейность — через признаки: полиномы, биннинг, WoE, взаимодействия.

## Почему её любят в банках
- Интерпретируемость (вес = вклад, скоркарты с баллами).
- Хорошо **откалиброванные вероятности** (PD — probability of default).
- Стабильность, простота валидации у регулятора.
- Типичный пайплайн скоринга: биннинг → **WoE** → отбор по **IV** → логрег → скоркарта.

IV: $\sum_i(\%good_i - \%bad_i)\cdot WoE_i$; <0.02 бесполезен, 0.1–0.3 средний, >0.5 подозрительно (утечка?).

## Связь с нейросетями
Логрег = **один нейрон с сигмоидой** = последний слой любой нейросети-классификатора. → [[4.1 Нейрон и MLP]]
