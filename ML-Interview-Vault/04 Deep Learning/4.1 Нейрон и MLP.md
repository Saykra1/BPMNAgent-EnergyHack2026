# 4.1 Нейрон и многослойный перцептрон (MLP)

## Искусственный нейрон
$$a = \varphi\Big(\sum_i w_ix_i + b\Big) = \varphi(w^\top x + b)$$
```
 x₁ ──w₁──╮
 x₂ ──w₂──┼──▶ [ Σ + b ] ──▶ [ φ ] ──▶ a
 x₃ ──w₃──╯      линейная     нелинейная
                  часть        активация
```
- $\varphi$ = сигмоида → это [[3.2 Логистическая регрессия]].
- $\varphi$ = ступенька → перцептрон Розенблатта (1958). Один нейрон **не решает XOR** (линейная граница) → нужны слои.

## MLP (полносвязная сеть)
```
  Вход        Скрытый 1      Скрытый 2      Выход
  (d)          (h₁)           (h₂)          (K)
  ○ ─────┬──▶  ○  ─────┬──▶   ○   ─────┬──▶ ○  ┐
  ○ ──╳──┼──▶  ○  ──╳──┼──▶   ○   ──╳──┼──▶ ○  ├ softmax → p(y|x)
  ○ ─────┴──▶  ○  ─────┴──▶   ○   ─────┴──▶ ○  ┘
             ReLU           ReLU
  h¹ = φ(W¹x + b¹),  h² = φ(W²h¹ + b²),  ŷ = softmax(W³h² + b³)
```
- Каждый слой: **линейное преобразование + нелинейность**.
- **Без нелинейности** любое число слоёв = одно линейное преобразование: $W_3W_2W_1x = Wx$. Нелинейность — ключ!
- Число параметров слоя: $d_{in}\cdot d_{out} + d_{out}$.

## Универсальная теорема аппроксимации
MLP с **одним** скрытым слоем достаточной ширины и нелинейной активацией может аппроксимировать любую непрерывную функцию на компакте с любой точностью. **Но**: ничего не говорит о том, сколько нейронов нужно и как их обучить. На практике **глубина эффективнее ширины** (иерархия признаков, экспоненциально меньше параметров).

## Выходной слой и лосс
| Задача | Выход | Лосс |
|---|---|---|
| Регрессия | линейный | MSE / MAE / Huber |
| Бинарная | 1 нейрон + sigmoid | BCE |
| Многоклассовая | K нейронов + softmax | Cross-entropy |
| Multi-label | K нейронов + sigmoid | BCE на каждый |

**Softmax**: $\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_je^{z_j}}$. Численно стабильно: вычесть $\max z$ (не меняет результат). Softmax с температурой $T$: $e^{z_i/T}$ — $T\to0$ argmax, $T\to\infty$ равномерное (→ [[5.11 Генерация и декодирование]], дистилляция).

## Цикл обучения
```mermaid
flowchart LR
    B[Батч] --> F[Forward pass<br/>ŷ = f(x; W)] --> L[Loss<br/>L(ŷ, y)] --> BW[Backward pass<br/>∂L/∂W] --> U[Optimizer step<br/>W ← W − η·∇] --> B
```
```python
for x, y in loader:
    optimizer.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()          # backprop
    optimizer.step()         # обновление весов
```
Эпоха — один проход по всему датасету. Итерация — один батч.
