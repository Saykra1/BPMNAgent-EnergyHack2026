# 4.10 Эмбеддинги слов

## От one-hot к плотным векторам
- **One-hot**: словарь 50k → вектор 50k с одной единицей. Огромный, разреженный, **все слова равноудалены** (нет семантики).
- **Эмбеддинг**: плотный вектор (100–4096 dim), похожие слова — близкие векторы.
- Embedding-слой = lookup-таблица $E\in\mathbb R^{|V|\times d}$ = умножение one-hot на матрицу.

**Дистрибутивная гипотеза**: «слово определяется своим контекстом» (Firth).

## Word2Vec (2013) ⭐
Неглубокая сеть, обучаемая предсказывать контекст:
```
 CBOW: контекст → слово           Skip-gram: слово → контекст
 [the] [cat] _ [on] [mat]          [sat] → [the],[cat],[on],[mat]
        ↘ ↓ ↙                       лучше для редких слов
         sat
```
- Обучение full softmax по словарю дорого → **Negative Sampling** (бинарная классификация: настоящая пара vs случайные «негативы»): $\log\sigma(u_o^\top v_c) + \sum_{k}\log\sigma(-u_k^\top v_c)$; или hierarchical softmax.
- Субсэмплинг частых слов.
- Знаменитая арифметика: $\vec{king} - \vec{man} + \vec{woman}\approx\vec{queen}$.
```
       king ●───────→● queen
            │         │      ← одинаковый вектор «пол»
        man ●───────→● woman
```

## GloVe
Факторизация матрицы совстречаемости: $w_i^\top\tilde w_j + b_i + \tilde b_j \approx \log X_{ij}$. Глобальная статистика + локальный контекст.

## FastText
Слово = сумма эмбеддингов **символьных n-грамм** («where» → <wh, whe, her, ere, re>). ✅ Работает с **OOV** (незнакомыми) словами, хорош для морфологически богатых языков (**русский**!).

## Ограничения статических эмбеддингов
**Одно слово — один вектор** независимо от контекста: «**замок** на двери» vs «средневековый **замок**», «**лук**» (оружие/овощ). → **Контекстные эмбеддинги**: ELMo (biLSTM, 2018) → **BERT** ([[5.6 BERT и encoder-модели]]) — вектор зависит от всего предложения.

## Эмбеддинги предложений / документов
- Усреднение word-векторов (+TF-IDF веса) — простой бейзлайн.
- Doc2Vec.
- **Sentence-BERT**, E5, BGE, multilingual-e5 — трансформеры, обученные контрастивно (InfoNCE) → семантический поиск, [[5.15 RAG и агенты|RAG]], кластеризация.

## Эмбеддинги не только для слов
item2vec (рекомендации), категориальные признаки в нейросетях, graph embeddings (node2vec), CLIP (картинка+текст).
