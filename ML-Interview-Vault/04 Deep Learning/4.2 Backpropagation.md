# 4.2 Backpropagation ⭐⭐⭐

**Backprop** = эффективное вычисление градиентов лосса по всем весам через **chain rule** ([[1.2 Матанализ и градиенты]]), проходя граф вычислений **от выхода к входу**, переиспользуя промежуточные результаты.

## Вычислительный граф
Пример: $L = (\sigma(wx+b) - y)^2$
```
 Forward →
   x ─┐
      (×)── u=wx ──(+)── z=u+b ──[σ]── a=σ(z) ──(−y)──[²]── L
   w ─┘            b ─┘
 ← Backward
   ∂L/∂a = 2(a−y)
   ∂L/∂z = ∂L/∂a · σ(z)(1−σ(z))
   ∂L/∂b = ∂L/∂z · 1
   ∂L/∂w = ∂L/∂z · x
```

## Для слоя в матричной форме
Слой: $z = Wx + b$, $a = \varphi(z)$. Пусть пришёл $\delta = \frac{\partial L}{\partial a}$ сверху.
$$\frac{\partial L}{\partial z} = \delta\odot\varphi'(z),\qquad \frac{\partial L}{\partial W} = \frac{\partial L}{\partial z}\,x^\top,\qquad \frac{\partial L}{\partial b} = \frac{\partial L}{\partial z},\qquad \frac{\partial L}{\partial x} = W^\top\frac{\partial L}{\partial z}$$
Последнее передаётся **в предыдущий слой**. Так и «распространяется ошибка назад».

## Стоимость
Backward ≈ **2× forward** по FLOPs. Требует **хранить активации** всех слоёв с forward pass → основное потребление памяти при обучении (решение: **gradient checkpointing** — пересчитываем часть активаций на backward, жертвуя временем ради памяти).

## Autograd
PyTorch строит граф динамически (define-by-run), `loss.backward()` проходит его в обратном порядке (reverse-mode автодифференцирование — эффективно, когда выход скалярный, а входов много).

## Проблемы градиентов ⭐
Градиент на слое $l$ — произведение многих множителей: $\frac{\partial L}{\partial h_1} = \prod_l W_l^\top\,\text{diag}(\varphi'(z_l))\cdots$

| Проблема | Причина | Решения |
|---|---|---|
| **Затухающие градиенты** (vanishing) | множители < 1: sigmoid' ≤ 0.25, tanh, малые веса, длинные RNN | ReLU, **residual connections**, BatchNorm/LayerNorm, правильная инициализация (He/Xavier), LSTM/GRU |
| **Взрывающиеся градиенты** (exploding) | множители > 1, большие веса, RNN | **gradient clipping**, инициализация, нормализация, меньший lr |

```
 Норма градиента по слоям:
 vanishing:  выход ████████ ████ ██ █ ▌ · · вход   (первые слои не учатся)
 exploding:  выход █ ██ ████ ████████ ████████████ → NaN
```

**Gradient clipping**: `clip_grad_norm_(params, max_norm=1.0)` — если $\|g\|>c$, то $g \leftarrow c\frac{g}{\|g\|}$.

## Residual connection — почему спасает
$h_{l+1} = h_l + F(h_l)$ ⇒ $\frac{\partial h_{l+1}}{\partial h_l} = I + \frac{\partial F}{\partial h_l}$. Слагаемое $I$ — «магистраль» для градиента, он не затухает. Основа ResNet и **трансформеров**.
