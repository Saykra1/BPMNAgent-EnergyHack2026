# 4.6 Нормализация: BatchNorm, LayerNorm, RMSNorm ⭐⭐⭐

## Общая формула
$$\hat x = \frac{x - \mu}{\sqrt{\sigma^2+\varepsilon}},\qquad y = \gamma\hat x + \beta$$
$\gamma,\beta$ — **обучаемые** масштаб и сдвиг (сеть может «отменить» нормализацию, если нужно). Разница — **по каким осям** считаются $\mu,\sigma$.

```
 Тензор активаций: N (батч) × C (каналы/фичи) × H×W (или L — длина последовательности)

  BatchNorm              LayerNorm             InstanceNorm          GroupNorm
  ┌─────────┐            ┌─────────┐           ┌─────────┐           ┌─────────┐
  │█ │ │ │ │ C           │█████████│ ← объект  │█ │ │ │ │           │███│ │ │ │
  │█ │ │ │ │             │ │ │ │ │ │           │ │ │ │ │ │           │ │ │ │ │ │
  │█ │ │ │ │             │ │ │ │ │ │           │ │ │ │ │ │           │ │ │ │ │ │
  └─────────┘            └─────────┘           └─────────┘           └─────────┘
   N  →                   N →                   N →                   N →
  по батчу для           по фичам для          по H,W для каждого    по группе каналов
  каждого канала         каждого объекта       объекта и канала
```

## BatchNorm (2015)
- Статистики **по батчу** для каждого признака/канала.
- **Train**: статистики батча + обновляем **running mean/var** (EMA).
- **Inference**: используем **накопленные** running mean/var (детерминированно) → важно вызывать `model.eval()`!
- ✅ Ускоряет обучение, позволяет больший lr, слабая регуляризация (шум батча), снижает чувствительность к init.
- ❌ Зависит от **размера батча** (маленький батч → шумные статистики); плохо для RNN и последовательностей переменной длины; различие train/eval — источник багов; проблемы при распределённом обучении (SyncBN).
- Почему работает: изначально «internal covariate shift», сейчас считается — **сглаживает ландшафт лосса**.
- Где: **CNN**.

## LayerNorm (2016) ⭐
- Статистики **по признакам одного объекта** (для токена — по $d_{model}$).
- Одинаково в train и eval, **не зависит от батча**.
- Где: **RNN, трансформеры**.

## RMSNorm ⭐
$$y = \frac{x}{\sqrt{\frac1d\sum x_i^2+\varepsilon}}\cdot\gamma$$
LayerNorm без вычитания среднего и без $\beta$. Дешевле, качество то же. **LLaMA, Mistral, Qwen и почти все современные LLM.**

## Другие
- **GroupNorm** — группы каналов; детекция/сегментация с маленькими батчами.
- **InstanceNorm** — style transfer.
- **Weight Norm**, **Spectral Norm** (GAN — ограничивает константу Липшица).

## Pre-LN vs Post-LN (трансформеры)
```
 Post-LN (оригинал 2017):  x → [Attn] → (+x) → LN → ...
 Pre-LN (GPT-2+, LLaMA):   x → LN → [Attn] → (+x) → ...
```
Pre-LN: «чистый» residual путь → стабильнее градиенты, можно без долгого warmup; стандарт в LLM. Post-LN: иногда лучше качество, но тяжелее обучать. → [[5.4 Архитектура Transformer]]
