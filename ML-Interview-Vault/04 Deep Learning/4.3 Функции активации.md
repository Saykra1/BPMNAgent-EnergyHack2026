# 4.3 Функции активации

```
  sigmoid           tanh             ReLU            Leaky ReLU        GELU
 1┤   ___        1┤   ___                 /               /                 /
  │ _-           │ _-               │    /           │    /          │    /
.5┤/            0┤/            0 ───┼───/         ───┼───/         ──┼──_/
  │            -1┤___            ───┘           ___/│             ‾‾‾ │(небольшой
 0┤___                                                                  провал <0)
```

| Активация | Формула | Производная | ✅ | ❌ |
|---|---|---|---|---|
| **Sigmoid** | $\frac1{1+e^{-x}}$ | $\sigma(1-\sigma)\le0.25$ | выход (0,1) — вероятности, гейты LSTM | насыщение → vanishing; не центрирована; exp дорогая |
| **Tanh** | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $1-\tanh^2$ | центрирована в 0 | насыщение |
| **ReLU** | $\max(0,x)$ | $[x>0]$ | дешёвая, нет насыщения при $x>0$, разреженность | **«мёртвые нейроны»** (если $z<0$ всегда — градиент 0 навсегда); не центрирована |
| **Leaky ReLU** | $\max(\alpha x, x)$, $\alpha=0.01$ | $1$ или $\alpha$ | нет мёртвых нейронов | |
| **PReLU** | $\alpha$ обучаемый | | | |
| **ELU** | $x$ или $\alpha(e^x-1)$ | | гладкая, среднее ближе к 0 | exp |
| **SELU** | масштабированная ELU | | самонормализация | специфичные условия |
| **GELU** ⭐ | $x\,\Phi(x)$ | | гладкая; **BERT, GPT** | дороже ReLU |
| **Swish / SiLU** | $x\,\sigma(\beta x)$ | | гладкая, немонотонная; EfficientNet, LLaMA | |
| **SwiGLU** ⭐ | $\text{Swish}(xW)\odot(xV)$ | | **LLaMA, PaLM, современные LLM** (FFN) | +параметры |
| **Softmax** | $\frac{e^{z_i}}{\sum e^{z_j}}$ | | выход многоклассовой, attention | |

## Правила выбора
- Скрытые слои: **ReLU** (CNN, MLP) по умолчанию; **GELU/SwiGLU** в трансформерах.
- Выход: sigmoid (бинарная/multi-label), softmax (многоклассовая), линейная (регрессия).
- Гейты (LSTM/GRU): sigmoid (0..1 «сколько пропустить») и tanh (значения −1..1).
