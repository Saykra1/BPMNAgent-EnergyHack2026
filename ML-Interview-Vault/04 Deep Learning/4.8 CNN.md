# 4.8 Свёрточные нейросети (CNN)

## Зачем свёртки
FC-слой на картинке 224×224×3 → 150k входов × N нейронов — огромно и не учитывает структуру. Свёртка использует **индуктивные смещения** изображений:
- **Локальность** — пиксели связаны с соседями.
- **Разделение весов** (weight sharing) — одно ядро скользит по всему изображению.
- **Эквивариантность к сдвигу** — объект сдвинулся → карта признаков сдвинулась.

## Операция свёртки
```
 Вход 5×5                Ядро 3×3        Выход 3×3
 ┌─┬─┬─┬─┬─┐            ┌──┬──┬──┐      ┌──┬──┬──┐
 │1│1│1│0│0│            │1 │0 │1 │      │4 │3 │4 │
 ├─┼─┼─┼─┼─┤            ├──┼──┼──┤      ├──┼──┼──┤
 │0│1│1│1│0│     ⊛      │0 │1 │0 │  =   │2 │4 │3 │
 ├─┼─┼─┼─┼─┤            ├──┼──┼──┤      ├──┼──┼──┤
 │0│0│1│1│1│            │1 │0 │1 │      │2 │3 │4 │
 ├─┼─┼─┼─┼─┤            └──┴──┴──┘      └──┴──┴──┘
 │0│0│1│1│0│   окно 3×3 скользит; в каждой позиции —
 ├─┼─┼─┼─┼─┤   поэлементное произведение и сумма
 │0│1│1│0│0│
 └─┴─┴─┴─┴─┘
```

### Размер выхода ⭐
$$O = \left\lfloor\frac{I - K + 2P}{S}\right\rfloor + 1$$
$I$ — вход, $K$ — ядро, $P$ — padding, $S$ — stride. «Same» padding при $S=1$: $P = (K-1)/2$.

### Параметры слоя
$C_{out}\times(C_{in}\cdot K\cdot K + 1)$. Пример: 3→64 каналов, 3×3: $64\cdot(3\cdot9+1) = 1792$.

- **Padding** — сохранить размер, учесть края.
- **Stride** — шаг (>1 уменьшает размер).
- **Dilation** — «дырявое» ядро, расширяет receptive field без параметров (сегментация, WaveNet).
- **1×1 свёртка** — смешивание каналов, изменение числа каналов (bottleneck).
- **Depthwise separable** (MobileNet) = depthwise (по каналу) + pointwise 1×1 → в ~$K^2$ раз дешевле.
- **Transposed conv** — апсемплинг (декодеры, GAN, U-Net).

## Pooling
Max pooling 2×2 stride 2 — уменьшает размер в 2 раза, даёт небольшую инвариантность к сдвигам, без параметров. **Global Average Pooling** — в конце вместо FC-слоёв.

## Receptive field
Область входа, влияющая на нейрон. Растёт с глубиной: два слоя 3×3 = RF 5×5, три = 7×7 (меньше параметров и больше нелинейностей, чем одно 7×7 — идея VGG).

## Иерархия признаков
```
 Слой 1: края, цвета  →  Слой 2: текстуры, углы  →  Слой 3: части (глаз, колесо)  →  Глубже: объекты
```

## Типичная архитектура
```
 [Image] → (Conv → BN → ReLU) ×n → Pool → (Conv → BN → ReLU) ×n → Pool → ... → GAP → FC → Softmax
          пространственный размер ↓, число каналов ↑
```

## Эволюция архитектур
| Год | Модель | Вклад |
|---|---|---|
| 1998 | LeNet | первая CNN (цифры) |
| 2012 | **AlexNet** | ReLU, dropout, GPU, ImageNet прорыв |
| 2014 | **VGG** | глубина, только 3×3 |
| 2014 | GoogLeNet/Inception | параллельные ветви разных размеров, 1×1 |
| 2015 | **ResNet** ⭐ | **skip connections** $y = F(x)+x$ → 152+ слоёв |
| 2017 | DenseNet | конкатенация всех предыдущих слоёв |
| 2017 | MobileNet | depthwise separable — мобильные |
| 2019 | EfficientNet | compound scaling (глубина, ширина, разрешение) |
| 2020 | **ViT** | трансформер на патчах → [[5.14 ViT и мультимодальность]] |
| 2022 | ConvNeXt | CNN, модернизированная идеями ViT |

### ResNet — почему работает
Проблема **деградации**: глубокие plain-сети хуже неглубоких даже на train (не переобучение — оптимизация!). Residual: слою проще выучить $F(x)=0$ (тождество), чем $H(x)=x$. Градиент течёт по skip-пути. → [[4.2 Backpropagation#Residual connection — почему спасает]]
```
 x ──┬──▶ [Conv-BN-ReLU-Conv-BN] ──▶ (+) ──▶ ReLU ──▶
     └────────────── identity ──────────┘
```

## Задачи CV
- **Классификация**.
- **Детекция**: двухстадийные (Faster R-CNN: RPN + классификация), одностадийные (**YOLO**, SSD, RetinaNet), трансформерные (DETR). Метрики: IoU, mAP. NMS для удаления дублей.
- **Сегментация**: семантическая (**U-Net**, DeepLab), instance (Mask R-CNN), panoptic; SAM.
- **OCR, лица (ArcFace), метрическое обучение.**
