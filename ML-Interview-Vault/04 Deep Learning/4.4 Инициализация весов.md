# 4.4 Инициализация весов

## Зачем
- **Все нули** (или одинаковые) → **симметрия**: все нейроны слоя получают одинаковый градиент и остаются одинаковыми. Сеть = 1 нейрон на слой. (Bias можно инициализировать нулями.)
- **Слишком большие** → насыщение активаций / взрыв.
- **Слишком маленькие** → сигнал и градиент затухают.

Цель: **сохранять дисперсию** активаций при прямом проходе и градиентов при обратном.

## Вывод интуиции
$z = \sum_{i=1}^{n_{in}} w_ix_i$ ⇒ $\mathrm{Var}(z) = n_{in}\,\mathrm{Var}(w)\,\mathrm{Var}(x)$. Хотим $\mathrm{Var}(z)=\mathrm{Var}(x)$ ⇒ $\mathrm{Var}(w) = \frac1{n_{in}}$.

| Схема | $\mathrm{Var}(w)$ | Для активаций |
|---|---|---|
| **Xavier / Glorot** | $\frac{2}{n_{in}+n_{out}}$ | tanh, sigmoid, линейные |
| **He / Kaiming** | $\frac{2}{n_{in}}$ (×2, т.к. ReLU обнуляет половину) | **ReLU** и родственные |
| LeCun | $\frac1{n_{in}}$ | SELU |
| Orthogonal | ортогональные матрицы | RNN |

```
 Дисперсия активаций по слоям (10 слоёв):
 слишком малая init:  ████ ██ █ ▌ · · · · · ·   → всё в ноль
 He init + ReLU:      ████ ████ ████ ████ ████  ✅ стабильно
 слишком большая:     ████ ██████ ███████████…  → насыщение/взрыв
```

## В трансформерах
Нормальное с малым std (≈0.02), масштабирование residual-выходов на $1/\sqrt{2N}$ (GPT-2), плюс LayerNorm делает обучение менее чувствительным к init.
