# 4.12 Генеративные модели: AE, VAE, GAN, Diffusion

## Автоэнкодер (AE)
```
 x ──▶ [Encoder] ──▶ z (bottleneck, dim ≪ x) ──▶ [Decoder] ──▶ x̂        L = ‖x − x̂‖²
```
Не генеративная модель (латентное пространство «дырявое»), но полезна: сжатие, понижение размерности (нелинейный PCA), **поиск аномалий** (ошибка реконструкции), **denoising AE** (вход с шумом → чистый выход), предобучение.

## VAE (Variational Autoencoder)
Энкодер выдаёт **распределение** $q(z|x) = \mathcal N(\mu(x),\sigma^2(x))$, сэмплируем $z$, декодируем.
$$\mathcal L = \underbrace{\mathbb E_{q}[\log p(x|z)]}_{\text{реконструкция}} - \underbrace{D_{KL}(q(z|x)\,\|\,\mathcal N(0,I))}_{\text{регуляризация латентного пр-ва}}\quad\text{(ELBO)}$$
**Reparameterization trick**: $z = \mu + \sigma\odot\varepsilon$, $\varepsilon\sim\mathcal N(0,I)$ — случайность вынесена, градиент проходит через $\mu,\sigma$.
✅ Гладкое непрерывное латентное пространство (интерполяция). ❌ Размытые картинки.
VAE используется как сжимающий автоэнкодер в **Stable Diffusion** (latent diffusion).

## GAN (2014)
Игра двух сетей:
```
 шум z ─▶ [Генератор G] ─▶ фейк ──┐
                                   ├─▶ [Дискриминатор D] ─▶ реальное или фейк?
 реальные данные ─────────────────┘
```
$$\min_G\max_D\ \mathbb E_x[\log D(x)] + \mathbb E_z[\log(1-D(G(z)))]$$
✅ Резкие реалистичные изображения, быстрая генерация.
❌ Нестабильное обучение, **mode collapse** (генератор выдаёт однообразие), нет оценки правдоподобия.
Варианты: DCGAN, **WGAN** (расстояние Вассерштейна, gradient penalty), **StyleGAN**, CycleGAN (непарный перенос стиля), Pix2Pix.

## Диффузионные модели ⭐ (SOTA для изображений)
- **Прямой процесс**: постепенно добавляем гауссов шум за $T$ шагов, пока картинка не станет чистым шумом: $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\varepsilon$.
- **Обратный процесс**: нейросеть (U-Net или трансформер — DiT) учится **предсказывать шум** $\varepsilon_\theta(x_t,t)$; лосс $\|\varepsilon - \varepsilon_\theta(x_t,t)\|^2$.
- Генерация: из шума итеративно убираем предсказанный шум.
```
 x₀ 🐱 → x₁ ░🐱 → x₂ ▒▒ → ... → x_T ▓▓▓ (шум)     прямой (фиксированный)
 x₀ 🐱 ← x₁ ░🐱 ← x₂ ▒▒ ← ... ← x_T ▓▓▓            обратный (обучаемый)
```
- **Latent Diffusion (Stable Diffusion)**: диффузия в латентном пространстве VAE (дешевле).
- **Условная генерация**: текст через CLIP/T5-энкодер + cross-attention; **classifier-free guidance**.
- Ускорение: DDIM (меньше шагов), distillation, consistency models; **Flow Matching** (SD3, Flux).
✅ Качество, разнообразие, стабильное обучение. ❌ Медленная генерация (много шагов).
