# 4.9 Рекуррентные сети: RNN, LSTM, GRU

## Vanilla RNN
Обрабатывает последовательность **по шагу**, храня **скрытое состояние** $h_t$ (память):
$$h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t + b),\qquad y_t = W_{hy}h_t$$
Одни и те же веса на каждом шаге.

```
 Свёрнутая:        Развёрнутая во времени:
   ┌──┐              y₁        y₂        y₃
   │  ↓              ↑         ↑         ↑
 x→[RNN]→y     h₀ →[RNN]──h₁─→[RNN]──h₂─→[RNN]──h₃ →
   ↑  │              ↑         ↑         ↑
   └──┘              x₁        x₂        x₃
```

### Режимы
```
 one-to-many      many-to-one       many-to-many (seq2seq)   many-to-many (синхронно)
 (генерация       (классификация    (перевод)                (NER, POS-теггинг)
  подписи)         отзыва)
```

### Обучение: BPTT (Backprop Through Time)
Разворачиваем сеть и делаем backprop. $\frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^t W_{hh}^\top\text{diag}(\tanh'(\cdot))$ → **произведение многих матриц** → **затухание** (если $\|W\|<1$) или **взрыв** ($>1$) градиентов → RNN не помнит дальние зависимости (>10–20 шагов). Truncated BPTT, gradient clipping.

## LSTM (1997) ⭐
Добавлено **состояние ячейки** $c_t$ — «конвейерная лента», по которой информация течёт почти без изменений, и **гейты** (sigmoid 0..1 = сколько пропустить).

$$\begin{aligned}
f_t &= \sigma(W_f[h_{t-1},x_t]+b_f) && \text{forget gate — что забыть из } c\\
i_t &= \sigma(W_i[h_{t-1},x_t]+b_i) && \text{input gate — что записать}\\
\tilde c_t &= \tanh(W_c[h_{t-1},x_t]+b_c) && \text{кандидат на запись}\\
c_t &= f_t\odot c_{t-1} + i_t\odot\tilde c_t && \text{обновление памяти (аддитивно!)}\\
o_t &= \sigma(W_o[h_{t-1},x_t]+b_o) && \text{output gate}\\
h_t &= o_t\odot\tanh(c_t)
\end{aligned}$$

```
        c_{t-1} ──────(×)─────────(+)──────────────┬──── c_t
                       ↑f          ↑                │
                       │      (×)←─┘               tanh
                       │      ↑i  ↑c̃                │
                       │      │   │               (×)──── h_t
                     [σ]    [σ] [tanh]   [σ]→o────┘
                       └──────┴───┴───────┘
        h_{t-1}, x_t ──────────┘
```
**Почему решает vanishing**: $\frac{\partial c_t}{\partial c_{t-1}} = f_t$ — аддитивное обновление, если $f\approx1$, градиент проходит без затухания (как residual connection). Инициализация bias forget-гейта = 1.
Параметры: $4\cdot(d_h(d_h+d_x)+d_h)$.

## GRU (2014)
Упрощённый LSTM: 2 гейта, нет отдельного $c_t$.
$$z_t = \sigma(\cdot)\ \text{(update)},\quad r_t = \sigma(\cdot)\ \text{(reset)},\quad \tilde h_t = \tanh(W[r_t\odot h_{t-1}, x_t]),\quad h_t = (1-z_t)\odot h_{t-1} + z_t\odot\tilde h_t$$
Меньше параметров (3 блока вместо 4), быстрее, качество обычно сравнимое.

## Расширения
- **Bidirectional RNN** — два прохода (→ и ←), конкатенация; видит весь контекст (не для генерации!).
- **Stacked (deep) RNN** — несколько слоёв.
- **Teacher forcing** — при обучении генератора на вход подаём **истинный** предыдущий токен (а не предсказанный). Проблема **exposure bias** на инференсе → scheduled sampling.

## Ограничения RNN → почему пришли трансформеры
1. **Последовательная обработка** — нельзя распараллелить по времени → медленное обучение.
2. Даже LSTM плохо помнит **очень** дальние зависимости.
3. Вся информация сжимается в вектор фиксированного размера (bottleneck в seq2seq).
→ [[4.11 Seq2Seq и Attention]] → [[5.1 Self-Attention]].

Сейчас — ренессанс рекуррентности в виде **SSM (Mamba)**, RWKV: линейная сложность по длине, параллельное обучение.
