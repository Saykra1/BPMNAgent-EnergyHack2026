# ML / DL / Transformers — Obsidian vault для подготовки к собеседованию

**Как открыть:** Obsidian → «Open folder as vault» → выбрать папку `ML-Interview-Vault`.

**С чего начать:**
1. `00 Старт/00 План подготовки.md` — план по часам и чек-лист.
2. `Roadmap.canvas` — визуальная карта: что от чего зависит и в каком порядке учить.
3. `Canvas/*.canvas` — детальные карты по разделам с ключевыми идеями.
4. Заметки `01…05` — конспекты от простого к сложному (у каждой есть prev/next и блок вопросов).
5. `06 Собеседование` — вопросы-ответы, код с нуля, шпаргалка.

Формулы — LaTeX, схемы — Mermaid и ASCII (Obsidian рендерит из коробки).
