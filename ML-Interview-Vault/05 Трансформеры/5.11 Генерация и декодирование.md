# 5.11 Генерация текста и стратегии декодирования ⭐⭐

## Авторегрессионная генерация
```
 prompt → [LLM] → логиты |V| → (стратегия) → токен → добавить к входу → [LLM] → ... → до </s> или max_tokens
```

## Стратегии
### Greedy
Всегда $\arg\max$. ✅ Детерминированно, быстро. ❌ Скучно, **повторения/зацикливание**, локально оптимально ≠ глобально.

### Beam search
Держим $k$ лучших **частичных** последовательностей по суммарному log-prob.
```
 beam=2:      ┌─ "кот" (−0.5) ─┬─ "сидит" (−0.9) ✓
 <s> ─────────┤                └─ "спит"  (−1.2) ✓
              └─ "пёс" (−0.7) ─┬─ "лает"  (−1.5) ✗
                               └─ "спит"  (−1.0) ✓ ... оставляем 2 лучших
```
✅ Перевод, суммаризация (задачи с «правильным» ответом). ❌ Для открытой генерации — пресный, повторяющийся текст. Нужна **нормализация по длине** (иначе предпочитает короткие).

### Sampling с температурой
$$p_i = \frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}$$
```
 T → 0:   █▁▁▁▁   ≈ greedy, детерминированно
 T = 1:   █▅▃▂▁   исходное распределение
 T > 1:   ▅▅▄▄▄   плоско, «креативно», больше бреда
```

### Top-k sampling
Сэмплируем только из $k$ наиболее вероятных токенов (перенормировав). ❌ Фиксированное $k$ не учитывает форму распределения.

### Top-p (nucleus) sampling ⭐
Берём **минимальное множество токенов с суммарной вероятностью ≥ p** (например 0.9).
```
 Уверенное распределение:  [0.85, 0.08, 0.03, ...] → nucleus = 2 токена
 Неуверенное:              [0.1, 0.09, 0.09, 0.08, ...] → nucleus = много токенов
```
Адаптивно к уверенности модели.

### Другие
- **Min-p**: оставить токены с $p \ge p_{min}\cdot p_{max}$.
- **Repetition / frequency / presence penalty** — штраф уже использованным токенам.
- **Contrastive search**, typical sampling.
- **Structured / constrained decoding** — грамматика, JSON-схема (маскируем недопустимые токены).
- **Stop sequences**, max_new_tokens.

## Типичные настройки
| Задача | Настройки |
|---|---|
| Код, факты, извлечение, классификация | T=0 (greedy) или низкая |
| Чат | T≈0.7, top_p≈0.9 |
| Креатив | T≈1.0+, top_p 0.95 |
| Перевод | beam search 4–5 |
