# 5.6 BERT и encoder-only модели ⭐⭐

## BERT (Google, 2018) — Bidirectional Encoder Representations from Transformers
Стек энкодеров трансформера. **BERT-base**: 12 слоёв, $d$=768, 12 голов, 110M параметров. **BERT-large**: 24 / 1024 / 16, 340M.

## Вход
```
 [CLS] мой пёс милый [SEP] он любит играть [SEP]
   +     +   +    +    +    +   +     +      +     Token embeddings
  E_A   E_A E_A  E_A  E_A  E_B E_B   E_B    E_B    Segment embeddings
  E_0   E_1 E_2  E_3  E_4  E_5 E_6   E_7    E_8    Position embeddings (обучаемые)
```

## Предобучение
### 1. MLM — Masked Language Modeling ⭐
Маскируем **15%** токенов, предсказываем их по **двустороннему** контексту.
Из выбранных 15%: **80%** → `[MASK]`, **10%** → случайный токен, **10%** → без изменений.
*Зачем 80/10/10?* `[MASK]` не встречается при fine-tuning → mismatch; модель должна строить хорошее представление **каждого** токена, не зная, какой «испорчен».
```
 Вход:  Москва — [MASK] России
 Выход:          столица
```
### 2. NSP — Next Sentence Prediction
Является ли B продолжением A (50/50)? По `[CLS]`. Позже показано (RoBERTa), что **NSP бесполезен**.

Недостаток MLM: лосс только на 15% токенов (менее эффективно, чем CLM), не умеет генерировать.

## Fine-tuning
```
 Классификация текста:    [CLS] текст [SEP] → h_[CLS] → Linear → softmax
 Пары предложений (NLI):  [CLS] A [SEP] B [SEP] → h_[CLS] → Linear
 NER (токены):            каждому h_i → Linear → тег (B-PER, I-PER, O…)
 QA (SQuAD):              [CLS] вопрос [SEP] контекст → для каждого токена: start/end логиты
```
Также: эмбеддинги (mean pooling) → поиск, кластеризация; **cross-encoder** для ре-ранжирования в RAG.

## Потомки
| Модель | Что улучшили |
|---|---|
| **RoBERTa** | убрали NSP, больше данных и шагов, **динамическое** маскирование, большие батчи |
| **ALBERT** | факторизация эмбеддингов, общие веса между слоями (меньше параметров), SOP вместо NSP |
| **DistilBERT** | дистилляция: 40% меньше, 60% быстрее, 97% качества |
| **ELECTRA** | replaced token detection: генератор подменяет токены, дискриминатор угадывает какие — лосс на **всех** токенах → эффективнее |
| **DeBERTa** | disentangled attention (контент и позиция отдельно), лучший на GLUE/SuperGLUE |
| **XLM-R** | мультиязычный (100 языков) |
| **ModernBERT** (2024) | RoPE, длинный контекст 8k, GeGLU, FlashAttention |
| **Sentence-BERT** | сиамская сеть → эмбеддинги предложений |
| **E5, BGE, multilingual-e5** | контрастивные эмбеддеры для поиска |
| 🇷🇺 **ruBERT** (DeepPavlov), **ruBERT/ruRoBERTa (Sber AI)**, **sbert_large_nlu_ru**, **LaBSE** | русский язык |

## Когда encoder-only лучше LLM
Классификация, NER, эмбеддинги, ре-ранжирование при ограниченном бюджете: **в 100–1000 раз дешевле** decoder-LLM, быстрая, легко дообучается на тысячах примеров.
