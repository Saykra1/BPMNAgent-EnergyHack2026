# 5.7 GPT и decoder-only модели ⭐⭐⭐

## Идея
Стек **декодеров без cross-attention** с **causal mask**, обучаемый предсказывать **следующий токен** (Causal Language Modeling):
$$\mathcal L = -\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t})$$
Лосс на **каждом** токене (эффективнее MLM). Простота + масштабируемость → основа всех современных LLM.

```
 Вход:     <s>   Москва   —    столица
            ↓      ↓      ↓       ↓
         [ Decoder-блоки с causal mask ] ×N
            ↓      ↓      ↓       ↓
 Цель:   Москва    —   столица  России      ← сдвиг на 1
```

## Блок (современный, LLaMA-style)
```
 x ─┬─▶ RMSNorm ─▶ Masked MHA/GQA (+RoPE) ─▶ (+) ─┬─▶ RMSNorm ─▶ SwiGLU FFN ─▶ (+) ─▶
    └──────────────────────────────────────────┘   └─────────────────────────────┘
 ... ×N → RMSNorm → Linear (|V|) → softmax → p(next token)
```

## In-context learning (ICL) ⭐
Модель решает новую задачу по примерам **в промпте**, без изменения весов:
```
 Отзыв: "ужасно" → негатив
 Отзыв: "супер!" → позитив
 Отзыв: "норм, но дорого" → ???
```
- **Zero-shot** — только инструкция; **few-shot** — несколько примеров.
- **Chain-of-Thought (CoT)**: «давай подумаем шаг за шагом» → промежуточные рассуждения улучшают сложные задачи. Self-consistency — несколько цепочек + голосование.
- Эмерджентные способности появляются с масштабом.

## Prompt engineering
Роль/системный промпт, чёткие инструкции, примеры, формат вывода (JSON), разбиение задачи, CoT, ReAct (рассуждение + действия), few-shot подбор примеров по похожести.

## Почему decoder-only победил
- Одна цель (next token) = **любая задача** через текст.
- Лосс на всех токенах, простая архитектура, отлично масштабируется.
- KV-кэш делает генерацию эффективной.
- Генерация «из коробки».
