# 5.14 Vision Transformer и мультимодальность

## ViT (2020) — «An Image is Worth 16x16 Words»
```
 Картинка 224×224 → нарезаем на патчи 16×16 → 196 патчей
 ┌──┬──┬──┬──┐
 │p1│p2│p3│p4│   каждый патч (16·16·3 = 768) → Linear → эмбеддинг d
 ├──┼──┼──┼──┤   + обучаемые позиционные эмбеддинги
 │p5│p6│..│  │   + [CLS]-токен
 └──┴──┴──┴──┘
 [CLS] p1 p2 ... p196 → Transformer Encoder ×N → h_[CLS] → MLP head → класс
```
- Патч-эмбеддинг = свёртка с kernel=stride=16.
- **Слабые индуктивные смещения** (нет локальности и трансляционной эквивариантности как в CNN) → **нужно очень много данных** (JFT-300M) или сильная регуляризация/аугментация (**DeiT** + дистилляция). На малых данных CNN лучше; на больших ViT лучше.
- Глобальный receptive field с первого слоя.
- Варианты: **Swin** (иерархический, attention в окнах со сдвигом — для детекции/сегментации), DeiT, **MAE** (self-supervised: маскируем 75% патчей и восстанавливаем), **DINO/DINOv2** (self-distillation, отличные признаки), SAM (сегментация чего угодно).

## CLIP (OpenAI, 2021) ⭐
Контрастивное обучение на 400M пар (картинка, подпись):
```
            текст₁  текст₂  текст₃
 картинка₁ [ ✓·      ·       ·  ]
 картинка₂ [  ·      ✓·      ·  ]     максимизируем диагональ (InfoNCE),
 картинка₃ [  ·      ·       ✓· ]     минимизируем остальное
```
Image encoder (ViT) + text encoder (трансформер) → **общее пространство эмбеддингов**.
- **Zero-shot классификация**: сравниваем картинку с «a photo of a {класс}».
- Поиск картинок по тексту, текстовый энкодер в Stable Diffusion, основа VLM.

## Vision-Language Models (VLM)
```
 Image → [Vision encoder (ViT/CLIP)] → [Projector (MLP / Q-Former)] → визуальные токены ─┐
 Text  → токены ─────────────────────────────────────────────────────────────────────────┴→ [LLM] → ответ
```
**LLaVA**, BLIP-2, Flamingo (cross-attention), Qwen-VL, GPT-4V, Gemini (нативно мультимодальный), 🇷🇺 GigaChat Vision.
Обучение: (1) обучаем проектор на парах картинка-подпись при замороженных энкодере и LLM; (2) instruction tuning на визуальных диалогах.
