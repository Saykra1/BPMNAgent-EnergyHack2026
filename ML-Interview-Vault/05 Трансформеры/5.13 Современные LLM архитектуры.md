# 5.13 Современные LLM: что поменялось с 2017 года ⭐⭐

## Оригинальный Transformer → LLaMA-подобный
| Компонент | 2017 Transformer | Современная LLM (LLaMA 3, Qwen, Mistral, GigaChat) | Зачем |
|---|---|---|---|
| Архитектура | encoder-decoder | **decoder-only** | универсальность |
| Нормализация | LayerNorm, **Post-LN** | **RMSNorm, Pre-LN** | стабильность, скорость |
| Позиции | sinusoidal абсолютные | **RoPE** | относительные позиции, расширение контекста |
| Активация FFN | ReLU | **SwiGLU** | качество |
| Attention | MHA | **GQA** | меньше KV-кэш |
| Bias в линейных слоях | есть | **нет** | стабильность, простота |
| Dropout | 0.1 | 0 (данных много, 1 эпоха) | |
| Реализация | | **FlashAttention** | скорость, память |
| Контекст | 512 | 8k – 1M+ | |
| FFN | dense | dense или **MoE** | |
| Эмбеддинги | tied | часто untied | |

```
 LLaMA-блок:
 x ──┬──▶ RMSNorm ──▶ GQA(RoPE на Q,K) ──▶ (+) ──┬──▶ RMSNorm ──▶ SwiGLU ──▶ (+) ──▶
     └─────────────────────────────────────────┘    └───────────────────────────┘
```

## Альтернативы трансформеру
- **State Space Models (Mamba)**: селективное состояние, $O(n)$ по длине, быстрый инференс, константная память. Гибриды Jamba, Zamba.
- **RWKV**, RetNet — «RNN, которая обучается как трансформер».
- Пока трансформеры остаются доминирующими.
