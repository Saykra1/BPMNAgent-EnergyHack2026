# 5.2 Multi-Head Attention и маски ⭐⭐⭐

## Multi-Head Attention (MHA)
Один attention усредняет всё в одно распределение весов. **Несколько голов** позволяют параллельно смотреть на **разные типы связей** (синтаксис, кореференция, соседние слова, …) в разных подпространствах.

$$\text{head}_i = \text{Attention}(XW_Q^{(i)}, XW_K^{(i)}, XW_V^{(i)})$$
$$\text{MHA}(X) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W_O$$

Обычно $d_k = d_v = d_{model}/h$ → суммарная стоимость ≈ как у одной головы полной размерности.
Пример: $d_{model}=512$, $h=8$ → $d_k=64$.

```
               X (n × 512)
     ┌──────┬──────┼──────┬──────┐
   head₁  head₂  head₃  ...   head₈      каждая: Q,K,V (n×64) → attention → (n×64)
     │      │      │            │
     └──────┴──── concat ───────┘        (n × 512)
                   │
                 × W_O (512×512)          смешивание голов
                   │
                 Out (n × 512)
```
На практике: одна большая матрица $W_{QKV}$, затем `reshape` на $(B, h, n, d_k)$.

**Параметры MHA**: $4\,d_{model}^2$ (+bias) — $W_Q, W_K, W_V, W_O$.

## Маски ⭐
Маска добавляет $-\infty$ к запрещённым позициям **до softmax** → вес = 0.

### Padding mask
Батч последовательностей разной длины дополняется `[PAD]`; на них смотреть нельзя.

### Causal (look-ahead) mask — для декодера/GPT
Токен $i$ видит только токены $\le i$ (нельзя подглядывать в будущее при обучении авторегрессии).
```
            k₁  k₂  k₃  k₄
     q₁  [  ✓   −∞  −∞  −∞ ]
     q₂  [  ✓   ✓   −∞  −∞ ]       нижнетреугольная
     q₃  [  ✓   ✓   ✓   −∞ ]
     q₄  [  ✓   ✓   ✓   ✓  ]
```
Благодаря маске при обучении предсказываем **все n следующих токенов параллельно за один проход** (teacher forcing), а не по одному.

### Другие
- **Bidirectional** (BERT) — без causal маски, видит всё.
- **Prefix LM** — префикс видит себя целиком, генерация — causal.
- **Sliding window** (Mistral, Longformer) — только $w$ ближайших.

## Варианты голов для ускорения инференса
```
  MHA                   GQA (groups=2)          MQA
  Q: ■ ■ ■ ■            Q: ■ ■ ■ ■              Q: ■ ■ ■ ■
  K: ■ ■ ■ ■            K: ■   ■                K: ■
  V: ■ ■ ■ ■            V: ■   ■                V: ■
  каждой Q своя K/V     группа Q делит K/V      все Q делят одну K/V
```
- **MQA (Multi-Query)** — одна K/V на все головы: KV-кэш меньше в $h$ раз, но качество чуть падает.
- **GQA (Grouped-Query)** ⭐ — компромисс: LLaMA-2 70B, LLaMA-3, Mistral, Qwen.
- **MLA (Multi-head Latent Attention, DeepSeek-V2/V3)** — K/V сжимаются в низкоранговый латентный вектор.
