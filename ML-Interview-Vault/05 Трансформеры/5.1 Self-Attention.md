# 5.1 Self-Attention ⭐⭐⭐

> Предпосылка: [[4.11 Seq2Seq и Attention]] (Q/K/V как мягкий поиск).

## Интуиция
В предложении «**Животное** не перешло улицу, потому что **оно** устало» — чтобы понять «оно», слову нужно «посмотреть» на «животное». Self-attention даёт **каждому токену** возможность собрать информацию **со всех токенов** последовательности с весами, которые зависят от содержания.

```
            Животное  не  перешло  улицу  потому  что  оно  устало
 «оно» →     ████     ·     ▌       ██     ·      ·    ██     █
             0.55   0.01  0.05     0.15   0.01  0.01  0.14  0.08
```

## Шаги
Вход: $X\in\mathbb R^{n\times d_{model}}$ ($n$ токенов).

**1. Проекции** (обучаемые матрицы):
$$Q = XW_Q,\quad K = XW_K,\quad V = XW_V,\qquad W_Q,W_K\in\mathbb R^{d_{model}\times d_k},\ W_V\in\mathbb R^{d_{model}\times d_v}$$
- **Q** — «что я ищу», **K** — «что я содержу (по чему меня искать)», **V** — «что я отдам, если меня выбрали».

**2. Scores**: $S = QK^\top\in\mathbb R^{n\times n}$ — попарная похожесть всех токенов.

**3. Масштабирование**: $S/\sqrt{d_k}$.

**4. Softmax по строкам** → веса $A$, каждая строка суммируется в 1.

**5. Взвешенная сумма**: $\text{Out} = AV$.

$$\boxed{\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V}$$

```
   X (n×d)
    │──×W_Q──▶ Q (n×dk) ─┐
    │──×W_K──▶ K (n×dk) ─┴─▶ QKᵀ (n×n) ─▶ ÷√dk ─▶ [mask] ─▶ softmax ─▶ A (n×n)
    │──×W_V──▶ V (n×dv) ──────────────────────────────────────────────────┐   │
                                                                          ▼   ▼
                                                                    Out = A·V  (n×dv)
```

## Зачем делить на $\sqrt{d_k}$ ⭐ (частый вопрос!)
Если компоненты $q,k$ независимы с нулевым средним и единичной дисперсией, то $q\cdot k = \sum_{i=1}^{d_k}q_ik_i$ имеет **дисперсию $d_k$**. При больших $d_k$ скоры огромные → softmax **насыщается** (почти one-hot) → **градиенты ≈ 0**. Деление на $\sqrt{d_k}$ возвращает дисперсию к 1.

```
 softmax без масштабирования (d_k=512):  [0.00, 1.00, 0.00, 0.00]  ← градиенты исчезают
 с масштабированием:                     [0.15, 0.55, 0.20, 0.10]  ← мягко, учится
```

## Свойства
- **Сложность**: $O(n^2\cdot d)$ по времени и $O(n^2)$ по памяти (матрица $A$) → проблема длинного контекста → [[5.12 Эффективность и инференс]].
- **Параллельность**: все позиции считаются одним матричным умножением (в отличие от RNN).
- **Длина пути** между любыми токенами — $O(1)$ (RNN — $O(n)$).
- **Перестановочная эквивариантность**: без позиционной информации attention не знает порядка слов! («кот съел мышь» = «мышь съела кот») → [[5.3 Позиционное кодирование]].
- Веса **динамические** (зависят от входа), в отличие от свёртки/FC.

| Слой | Сложность на слой | Последовательные операции | Макс. длина пути |
|---|---|---|---|
| Self-Attention | $O(n^2d)$ | $O(1)$ | $O(1)$ |
| RNN | $O(nd^2)$ | $O(n)$ | $O(n)$ |
| CNN | $O(knd^2)$ | $O(1)$ | $O(\log_k n)$ |

## Self- vs Cross-attention
- **Self-attention**: Q, K, V из **одной** последовательности.
- **Cross-attention**: Q из декодера, K и V — из энкодера (перевод, Stable Diffusion: Q — картинка, K/V — текст).

## Код (NumPy)
```python
def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.swapaxes(-1, -2) / np.sqrt(d_k)
    if mask is not None:
        scores = np.where(mask, scores, -1e9)
    scores -= scores.max(-1, keepdims=True)          # стабильность
    w = np.exp(scores); w /= w.sum(-1, keepdims=True)
    return w @ V, w
```
