# 5.8 T5 и encoder-decoder модели

## T5 (Google, 2019) — Text-To-Text Transfer Transformer
**Любая задача = текст на вход → текст на выход.**
```
 "translate English to German: That is good."   → "Das ist gut."
 "cola sentence: The course is jumping well."   → "not acceptable"
 "summarize: длинная статья ..."                 → "краткое содержание"
 "stsb sentence1: ... sentence2: ..."            → "3.8"
```
Полный encoder-decoder; относительные позиционные bias; обучен на **C4** (очищенный Common Crawl).

### Предобучение: span corruption
Заменяем **спаны** (непрерывные куски) на сентинели, декодер восстанавливает:
```
 Вход:  Благодарю <X> на вечеринку <Y> неделе.
 Цель:  <X> вас за приглашение <Y> на прошлой <Z>
```

## BART (Facebook, 2019)
Denoising autoencoder: энкодер (как BERT) + декодер (как GPT). Шумы: маскирование, удаление, перестановка предложений, **text infilling**. Силён в **суммаризации**.

## Другие
- **mT5, mBART** — мультиязычные.
- **FRED-T5** (Сбер, русский) — смесь денойзеров (UL2-стиль).
- **UL2** — Mixture of Denoisers.
- **Whisper** (речь → текст), оригинальный трансформер для перевода, **Flan-T5** (instruction-tuned).

## Когда encoder-decoder
Вход и выход **разной природы/длины**: перевод, суммаризация, ASR, генерация по структурированному входу. Энкодер читает вход **двунаправленно** один раз; декодер генерирует с cross-attention.
Но на огромных масштабах decoder-only проще и универсальнее → индустрия ушла в decoder-only.
