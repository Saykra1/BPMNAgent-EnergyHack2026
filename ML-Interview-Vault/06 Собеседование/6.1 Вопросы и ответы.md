# 6.1 Вопросы и ответы для собеседования

> [!tip] Как тренироваться
> Закрой ответ (свернуть callout), ответь **вслух за 1–2 минуты**, потом сверься. Структура ответа: **определение → интуиция/картинка → формула → плюсы/минусы → пример из практики**.

## Основы ML

> [!question]- Что такое переобучение и как с ним бороться?
> Модель запоминает шум train-выборки: train-ошибка низкая, val — высокая (high variance). Бороться: больше данных, регуляризация (L1/L2, dropout), упрощение модели, early stopping, аугментации, кросс-валидация для контроля, ансамбли (бэггинг), отбор признаков. → [[2.2 Bias-Variance и переобучение]]

> [!question]- Объясни bias-variance tradeoff
> Ошибка = bias² + variance + шум. Bias — систематическая ошибка из-за слишком простой модели; variance — чувствительность к конкретной выборке у сложной модели. Рост сложности снижает bias и повышает variance; ищем баланс. Пример: kNN с k=1 — низкий bias, высокая variance; k=n — наоборот.

> [!question]- L1 vs L2?
> L2 штрафует квадраты весов, равномерно уменьшает их, не зануляет, имеет аналитическое решение, гауссов prior. L1 — модули, зануляет веса (отбор признаков) из-за углов ромба ограничений на осях, prior Лапласа. Elastic Net — комбинация. → [[2.3 Регуляризация]]

> [!question]- Precision vs Recall, что выбрать?
> Precision = TP/(TP+FP) — доля верных среди предсказанных положительных; Recall = TP/(TP+FN) — доля найденных положительных. Дорог FP (спам-фильтр, одобрение кредита мошеннику с точки зрения клиента) → precision; дорог FN (болезнь, фрод) → recall. Компромисс через порог, F-β.

> [!question]- Что такое ROC-AUC? Как интерпретировать?
> Площадь под кривой TPR(FPR) по всем порогам. = вероятность, что случайный положительный объект получит скор выше случайного отрицательного. 0.5 — случайно, 1 — идеально. Не зависит от порога и монотонных преобразований. При сильном дисбалансе лучше смотреть PR-AUC. В банке Gini = 2·AUC − 1.

> [!question]- Как валидировать модель на временных данных?
> Только по времени: TimeSeriesSplit / expanding window / backtesting; train всегда раньше val; признаки (лаги, окна) считать без заглядывания в будущее; иногда gap между train и val.

> [!question]- Что такое утечка данных? Примеры
> Попадание в обучение информации, недоступной в момент прогноза. Примеры: нормализация/target encoding на всём датасете, признаки из будущего, дубли в train/test, один клиент в train и test, случайный сплит временного ряда. Лечение: Pipeline, правильный сплит, out-of-fold кодирование.

> [!question]- Чем параметры отличаются от гиперпараметров?
> Параметры учатся на данных (веса), гиперпараметры задаются до обучения (lr, глубина, λ) и подбираются на валидации.

> [!question]- Что делать при дисбалансе классов?
> Правильные метрики (PR-AUC, F1), подбор порога, class weights, under/oversampling (SMOTE) только на train, focal loss, постановка как поиск аномалий. → [[3.14 Дисбаланс классов]]

## Классический ML

> [!question]- Выведи решение линейной регрессии
> $L = \|Xw-y\|^2$, $\nabla = 2X^\top(Xw-y) = 0$ ⇒ $w = (X^\top X)^{-1}X^\top y$. Если $X^\top X$ вырождена — Ridge $(X^\top X+\lambda I)^{-1}X^\top y$ или GD.

> [!question]- Почему логистическая регрессия — линейный классификатор?
> Граница $p=0.5 \Leftrightarrow w^\top x=0$ — гиперплоскость. Сигмоида лишь монотонно переводит расстояние до неё в вероятность.

> [!question]- Градиент log-loss для логрег
> $\nabla_w = \frac1n X^\top(\sigma(Xw) - y)$. Выводится через $\sigma' = \sigma(1-\sigma)$.

> [!question]- Как работает SVM? Что такое kernel trick?
> Максимизирует зазор между классами: min ‖w‖² при y(wᵀx+b)≥1 (soft margin — с hinge loss и C). Решение зависит только от опорных векторов. В двойственной задаче данные входят через скалярные произведения → заменяем на ядро K(x,z) = ⟨φ(x),φ(z)⟩ — неявно работаем в пространстве высокой размерности.

> [!question]- Как строится решающее дерево?
> Жадно: в каждом узле перебираем признаки и пороги, выбираем разбиение с максимальным уменьшением impurity (Gini/энтропия для классификации, MSE для регрессии). Останавливаемся по max_depth/min_samples_leaf. Переобучается — нужна регуляризация или ансамбль.

> [!question]- Bagging vs Boosting
> Бэггинг: параллельно, бутстрап, глубокие деревья, усреднение → снижает variance (RF). Бустинг: последовательно, каждая модель исправляет ошибки предыдущих (обучается на антиградиенте лосса), неглубокие деревья → снижает bias; может переобучиться при большом числе деревьев.

> [!question]- Почему Random Forest использует случайные признаки?
> Чтобы декоррелировать деревья: дисперсия среднего = ρσ² + (1−ρ)σ²/N, без декорреляции сильные признаки делают все деревья похожими.

> [!question]- Объясни градиентный бустинг
> Начинаем с константы; на каждом шаге считаем антиградиент лосса по текущим предсказаниям (для MSE — остатки), обучаем дерево его предсказывать, добавляем с шагом η. Это градиентный спуск в пространстве функций. XGBoost — второй порядок + регуляризация; LightGBM — leaf-wise, гистограммы, GOSS; CatBoost — ordered TS для категорий, симметричные деревья.

> [!question]- XGBoost vs LightGBM vs CatBoost
> См. таблицу в [[3.8 Градиентный бустинг#Сравнение]].

> [!question]- Как работает K-Means? Минусы?
> Инициализация центров (k-means++) → назначение к ближайшему центру → пересчёт центров → повтор. Минусы: нужно k, сферические кластеры, локальный минимум, чувствителен к выбросам и масштабу. Альтернативы: DBSCAN, GMM, иерархическая.

> [!question]- Как работает PCA?
> Центрируем данные, находим собственные векторы ковариационной матрицы (или SVD X), проецируем на компоненты с наибольшей дисперсией. Масштабирование обязательно.

> [!question]- Нужно ли масштабировать признаки для деревьев?
> Нет — разбиения инвариантны к монотонным преобразованиям. Для линейных, kNN, SVM, PCA, нейросетей — нужно.

## Deep Learning

> [!question]- Зачем нужны функции активации?
> Без нелинейности композиция линейных слоёв = один линейный слой.

> [!question]- Как работает backpropagation?
> Forward считает выход и сохраняет активации; backward идёт от лосса к входу, по chain rule умножая локальные производные; ∂L/∂W = δ·xᵀ, δ передаётся назад через Wᵀ. Один backward ≈ 2 forward.

> [!question]- Vanishing / exploding gradients — причины и решения
> Произведение многих множителей <1 или >1 при backprop. Решения: ReLU, residual connections, нормализация, He/Xavier init, LSTM/GRU, gradient clipping.

> [!question]- Как работает Adam? Чем AdamW лучше?
> Momentum (EMA градиентов) + RMSProp (EMA квадратов) + bias correction; шаг = η·m̂/(√v̂+ε). В Adam L2 через градиент масштабируется адаптивным делителем → неравномерная регуляризация; AdamW применяет weight decay к весам напрямую.

> [!question]- BatchNorm vs LayerNorm
> BN нормирует по батчу для каждого признака; на инференсе использует running статистики; зависит от размера батча; CNN. LN нормирует по признакам каждого объекта; одинаков в train/eval; RNN/трансформеры. RMSNorm — LN без центрирования (LLM).

> [!question]- Как работает dropout?
> На train зануляет нейроны с вероятностью p и масштабирует оставшиеся на 1/(1−p); на inference отключён. Предотвращает ко-адаптацию, неявный ансамбль.

> [!question]- Посчитай выход свёрточного слоя
> O = ⌊(I − K + 2P)/S⌋ + 1. Параметры: C_out·(C_in·K² + 1).

> [!question]- Зачем ResNet skip connections?
> Решают проблему деградации глубоких сетей: слою легче выучить остаток F(x)=H(x)−x; градиент течёт напрямую по identity-пути.

> [!question]- Как LSTM борется с затуханием градиента?
> Аддитивное обновление ячейки cₜ = f⊙cₜ₋₁ + i⊙c̃ₜ; при f≈1 градиент проходит почти без изменений; гейты регулируют поток.

> [!question]- Почему нельзя инициализировать веса нулями?
> Симметрия: все нейроны слоя получают одинаковые градиенты и остаются одинаковыми.

## Трансформеры и LLM

> [!question]- Напиши формулу attention, зачем √d_k?
> softmax(QKᵀ/√d_k)V. Дисперсия скалярного произведения растёт как d_k → softmax насыщается → градиенты исчезают; деление возвращает дисперсию к 1.

> [!question]- Зачем multi-head?
> Разные головы смотрят на разные типы зависимостей в разных подпространствах; стоимость как у одной головы.

> [!question]- Зачем позиционное кодирование? Что такое RoPE?
> Attention перестановочно эквивариантен. RoPE поворачивает Q и K на угол ∝ позиции, скалярное произведение зависит только от относительного смещения.

> [!question]- Опиши блок трансформера
> (Pre-LN) x + MHA(LN(x)) → x + FFN(LN(x)). Attention смешивает информацию между токенами, FFN обрабатывает каждый токен (хранит знания), residual + LN для стабильности. Декодер: causal mask (+ cross-attention в enc-dec).

> [!question]- BERT vs GPT
> BERT — encoder, двунаправленный, MLM, для понимания (классификация, NER, эмбеддинги). GPT — decoder, causal, next-token, для генерации и всего через промпт.

> [!question]- Сложность attention и как её снизить?
> O(n²d) по времени, O(n²) памяти. FlashAttention (точный, IO-aware), sparse/sliding window, linear attention, SSM.

> [!question]- Что такое KV-cache?
> При генерации K и V прошлых токенов не меняются → кэшируем, на каждом шаге считаем только новый токен. Размер 2·layers·kv_heads·d_head·len·bytes. Уменьшают GQA/MQA, квантизацией, PagedAttention.

> [!question]- Как обучают ChatGPT-подобные модели?
> Pretraining (next token на триллионах токенов) → SFT на инструкциях → выравнивание по предпочтениям (RLHF: reward model + PPO с KL-штрафом, или DPO) → (RL для рассуждений).

> [!question]- Как работает LoRA?
> W = W₀ + (α/r)·BA, r ≪ d, W₀ заморожена, B=0 при init. Обучаем <1% параметров, можно слить с весами — нет задержки на инференсе. QLoRA — то же поверх 4-битной базовой модели.

> [!question]- Температура, top-k, top-p
> T масштабирует логиты: T→0 greedy, T↑ — разнообразнее. Top-k — сэмплинг из k лучших; top-p — из минимального набора с суммарной вероятностью ≥ p (адаптивно).

> [!question]- RAG vs fine-tuning
> RAG — для знаний (свежих, приватных, с источниками), fine-tuning — для поведения/формата/стиля. Часто комбинируют.

> [!question]- Что такое BPE?
> Начинаем с символов/байтов, итеративно сливаем самую частую пару в новый токен до нужного размера словаря.

> [!question]- Что такое галлюцинации и как бороться?
> Правдоподобный, но неверный вывод. RAG с цитированием, низкая температура, инструкции «скажи не знаю», проверка (self-consistency, верификатор), fine-tuning на честность, constrained decoding.

## ML System Design

> [!question]- Спроектируй модель кредитного скоринга
> 1. **Цель**: PD — вероятность дефолта (90+ дней просрочки за 12 мес). Бизнес-метрика — ожидаемые потери / approval rate при фиксированном риске.
> 2. **Данные**: анкета, кредитная история (БКИ), транзакции, продукты банка. Агрегаты по окнам, WoE.
> 3. **Валидация**: out-of-time (последние месяцы), стабильность по поколениям (vintage).
> 4. **Модели**: бейзлайн логрег на WoE (интерпретируемо) → CatBoost/LightGBM. Калибровка.
> 5. **Метрики**: Gini, KS, калибровка, PSI (стабильность распределений).
> 6. **Проблемы**: reject inference (нет таргета у отказанных), дисбаланс, дрейф, интерпретируемость (SHAP для объяснения отказа), регуляторные требования, fairness.
> 7. **Деплой и мониторинг**: PSI признаков и скоров, Gini на свежих данных, переобучение.

> [!question]- Спроектируй систему антифрода по транзакциям
> Реальное время (<100 мс): правила + модель. Признаки: скоростные (число транзакций за минуту/час), отклонение от профиля клиента (сумма, гео, MCC, устройство), графовые (связи карт/устройств). Модель: бустинг + аномалии (Isolation Forest/автоэнкодер) для новых схем. Дисбаланс → PR-AUC, recall при фиксированной доле алертов. Задержка меток (чарджбэки приходят через недели), adversarial-дрейф → частое переобучение, мониторинг.

> [!question]- Спроектируй чат-бота поддержки на базе LLM
> RAG по базе знаний (чанкинг, гибридный поиск, reranker), LLM (GigaChat/открытая модель с LoRA под стиль), guardrails (PII, токсичность, prompt injection), маршрутизация на оператора при низкой уверенности, логирование, оценка (faithfulness, CSAT, доля решённых без оператора), A/B.

> [!question]- Общая схема ML-проекта
> Бизнес-задача и метрика → данные и разметка → EDA → бейзлайн → признаки и модели → оффлайн-валидация → A/B-тест → деплой (batch / online, latency) → мониторинг (data drift, concept drift, качество) → переобучение. MLOps: версионирование данных и моделей (DVC, MLflow), feature store, CI/CD.

> [!question]- Что такое data drift и concept drift?
> Data drift — меняется распределение p(x) (например, новые клиенты); concept drift — меняется связь p(y|x) (мошенники сменили схему). Мониторинг: PSI, KS-тест, качество на свежей разметке.
