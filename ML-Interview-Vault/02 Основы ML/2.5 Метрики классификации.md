# 2.5 Метрики классификации ⭐⭐⭐

## Матрица ошибок (Confusion Matrix)
```
                     Предсказано
                    Positive   Negative
 Факт  Positive  │   TP     │   FN     │  ← ошибка II рода (пропуск)
       Negative  │   FP     │   TN     │
                     ↑
               ошибка I рода (ложная тревога)
```

## Основные метрики
| Метрика | Формула | Смысл | Когда важна |
|---|---|---|---|
| **Accuracy** | $\frac{TP+TN}{\text{все}}$ | доля верных | только сбалансированные классы! |
| **Precision** | $\frac{TP}{TP+FP}$ | из предсказанных «1» сколько реально «1» | дорог FP: спам-фильтр, одобрение кредита |
| **Recall (TPR, Sensitivity)** | $\frac{TP}{TP+FN}$ | какую долю «1» нашли | дорог FN: болезни, фрод |
| **Specificity (TNR)** | $\frac{TN}{TN+FP}$ | доля найденных «0» | |
| **FPR** | $\frac{FP}{FP+TN}$ | | ось X ROC-кривой |
| **F1** | $\frac{2PR}{P+R}$ | гармоническое среднее | баланс P и R |
| **F-β** | $(1+\beta^2)\frac{PR}{\beta^2P+R}$ | β>1 — важнее recall | |

> [!example] Почему accuracy врёт
> 99% транзакций честные. Модель «всегда 0» → accuracy 99%, recall 0. Бесполезна.

> [!tip] Почему гармоническое, а не арифметическое среднее в F1?
> Гармоническое близко к **минимуму**: при P=1, R=0.01 → F1≈0.02, а арифметическое 0.5.

## Порог и trade-off
Модель выдаёт вероятность $p$; класс = $[p > t]$. Сдвиг $t$:
- $t\uparrow$ → precision↑, recall↓
- $t\downarrow$ → recall↑, precision↓

Порог подбирают под бизнес: максимум F1, заданный recall, минимум стоимости $c_{FP}FP + c_{FN}FN$.

## ROC-кривая и ROC-AUC ⭐
ROC = TPR (y) от FPR (x) при всех порогах.
```
 TPR
 1 │      ____-----‾‾‾‾  отличная модель (AUC≈0.95)
   │    /     ___----
   │   /   _-‾        хорошая
   │  / _-‾     ⁄
   │ /-‾     ⁄  ← случайная (AUC = 0.5)
   │/    ⁄
 0 └──────────────── FPR
   0                1
```
- **AUC = вероятность того, что случайный положительный объект получит скор выше случайного отрицательного.** (Ключевая интерпретация!)
- Не зависит от порога и от **монотонных преобразований** скоров (важен только порядок).
- Не зависит от баланса классов «напрямую», но при сильном дисбалансе **оптимистична** (FPR мал из-за огромного TN).
- **Gini = 2·AUC − 1** — стандарт в банковском скоринге (Сбер!).
- Вычисление: через сортировку, $O(n\log n)$; связь с U-статистикой Манна–Уитни.

## PR-кривая и PR-AUC (Average Precision)
Precision (y) от Recall (x). Baseline = доля положительных класса (а не 0.5).
- **Лучше ROC-AUC при сильном дисбалансе** (антифрод), т.к. не использует TN.

## Калибровка вероятностей
Модель **откалибрована**, если среди объектов с $p=0.8$ ровно 80% положительных.
- Логрег обычно откалиброван (оптимизирует log-loss). Бустинг, SVM, RF, наивный Байес — часто нет.
- **Методы**: Platt scaling (логрег поверх скоров), Isotonic regression, temperature scaling (нейросети).
- **Метрики**: Log-loss, Brier score $\frac1n\sum(p-y)^2$, ECE, reliability diagram.
- Важно для: кредитного скоринга (PD → ожидаемые потери), ставок, комбинации моделей.

## Многоклассовая классификация
- **Macro**-average: среднее метрик по классам (все классы равноправны).
- **Micro**-average: суммируем TP/FP/FN по всем классам (= accuracy для single-label).
- **Weighted**: среднее, взвешенное по числу объектов.
- **Top-k accuracy**, Cohen's kappa, MCC (Matthews — устойчив к дисбалансу).

## Log-loss как метрика
$-\frac1n\sum[y\log p + (1-y)\log(1-p)]$ — штрафует **уверенные ошибки** очень сильно. Оценивает качество вероятностей, а не только ранжирование.
