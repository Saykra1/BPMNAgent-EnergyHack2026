# 2.7 Предобработка данных и Feature Engineering

```mermaid
flowchart LR
    RAW[Сырые данные] --> EDA[EDA:<br/>распределения, пропуски,<br/>выбросы, корреляции]
    EDA --> CLEAN[Очистка:<br/>дубли, ошибки]
    CLEAN --> MISS[Пропуски]
    MISS --> OUT[Выбросы]
    OUT --> ENC[Кодирование<br/>категорий]
    ENC --> SCALE[Масштабирование]
    SCALE --> FE[Генерация<br/>признаков]
    FE --> FS[Отбор<br/>признаков]
    FS --> MODEL[Модель]
```

## Пропуски
| Метод | Комментарий |
|---|---|
| Удалить строки/столбцы | если пропусков мало / столбец почти пустой |
| Среднее / медиана / мода | просто; медиана робастнее |
| Константа + **флаг пропуска** `is_missing` | часто сам факт пропуска информативен! |
| kNN-импутация, MICE, модель | точнее, дороже |
| Ничего не делать | **бустинги (XGB/LGBM/CatBoost) умеют работать с NaN** нативно |
Типы: MCAR (полностью случайно), MAR (зависит от наблюдаемых), MNAR (зависит от самого значения).

## Выбросы
- Обнаружение: IQR ($<Q_1-1.5\,IQR$ или $>Q_3+1.5\,IQR$), z-score $>3$, Isolation Forest.
- Обработка: удалить, **клиппинг (винзоризация)**, log-трансформ, робастные лоссы (Huber/MAE), деревья (устойчивы).

## Масштабирование
| Метод | Формула | Когда |
|---|---|---|
| **StandardScaler** | $\frac{x-\mu}{\sigma}$ | линейные модели, SVM, kNN, PCA, нейросети |
| **MinMaxScaler** | $\frac{x-\min}{\max-\min}$ | нужен диапазон [0,1] (картинки) |
| **RobustScaler** | $\frac{x-\text{median}}{IQR}$ | есть выбросы |
| **Log / Box-Cox / Yeo-Johnson** | | тяжёлые хвосты, скошенность |
| **QuantileTransformer** | → равномерное/нормальное | |

> [!important] Кому НЕ нужно масштабирование
> **Деревьям и их ансамблям** (RF, бустинг) — они инвариантны к монотонным преобразованиям признака. Всем «метрическим» и градиентным моделям — нужно.

## Кодирование категориальных признаков
| Метод | Суть | ± |
|---|---|---|
| **One-Hot** | бинарный столбец на категорию | ✅ линейные модели; ❌ высокая кардинальность → взрыв размерности |
| **Label / Ordinal** | категория → число | ✅ деревья, порядковые; ❌ для линейных вводит ложный порядок |
| **Target (Mean) Encoding** | среднее таргета по категории | ✅ мощно; ❌ **утечка** → считать out-of-fold + сглаживание |
| **Frequency / Count** | частота категории | просто |
| **Ordered TS (CatBoost)** | target encoding по «прошлым» объектам | без утечки |
| **Hashing trick** | хэш → фикс. число бинов | огромная кардинальность |
| **Эмбеддинги** | обучаемые векторы | нейросети |
| **WoE (Weight of Evidence)** | $\ln\frac{\%\text{good}}{\%\text{bad}}$ | **банковский скоринг**; + IV для отбора |

Сглаживание target encoding: $\frac{n\cdot\bar y_{cat} + m\cdot\bar y_{global}}{n+m}$.

## Генерация признаков
- **Даты**: день недели, месяц, праздник, час, циклическое кодирование $\sin(2\pi t/T), \cos(2\pi t/T)$.
- **Агрегаты** (транзакции!): sum/mean/count/std по клиенту за 7/30/90 дней, доли по категориям MCC, тренды.
- **Взаимодействия**: произведения, отношения (долг/доход), полиномиальные.
- **Биннинг** (дискретизация) — для линейных моделей и WoE.
- **Текст**: BoW, TF-IDF, n-граммы, эмбеддинги (см. [[4.10 Эмбеддинги слов]]).
- **Гео**: расстояния, кластеры.
- **Лаги и скользящие окна** — [[3.13 Временные ряды]].

TF-IDF: $\text{tf}(t,d)\cdot\log\frac{N}{\text{df}(t)}$ — редкие в корпусе, но частые в документе слова важнее.

## Отбор признаков
| Тип | Методы |
|---|---|
| **Filter** | корреляция, χ², mutual information, IV, дисперсия |
| **Wrapper** | RFE, forward/backward selection |
| **Embedded** | L1 (Lasso), важности деревьев |
| **Другое** | permutation importance, SHAP, Boruta, adversarial validation |

Мультиколлинеарность: **VIF** $= \frac{1}{1-R_j^2}$ (>5–10 — плохо).

## Проклятие размерности
С ростом $d$ объём пространства растёт экспоненциально, данные становятся разреженными, **расстояния между точками выравниваются** → kNN, кластеризация ломаются. Лечение: отбор признаков, [[3.10 Понижение размерности]], регуляризация.
