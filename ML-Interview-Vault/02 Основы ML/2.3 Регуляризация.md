# 2.3 Регуляризация ⭐⭐⭐

**Идея**: штрафуем модель за сложность, чтобы уменьшить variance ценой небольшого роста bias.
$$L_{reg}(w) = L(w) + \lambda\,\Omega(w)$$

## L2 (Ridge, weight decay)
$$\Omega = \|w\|_2^2 = \sum w_j^2$$
- Веса **уменьшаются пропорционально**, но не обнуляются.
- Градиент штрафа $2\lambda w$ → «затухание весов» (weight decay).
- Решение линрег: $w = (X^\top X + \lambda I)^{-1}X^\top y$ — **всегда обратима**, лечит мультиколлинеарность.
- Байесовски: гауссов prior (см. [[1.4 Статистика и MLE]]).

## L1 (Lasso)
$$\Omega = \|w\|_1 = \sum |w_j|$$
- **Обнуляет** часть весов → **отбор признаков**, разреженные модели.
- Недифференцируема в 0 → координатный спуск / субградиент / proximal (soft-thresholding).
- При коррелированных признаках выбирает один случайно.
- Байесовски: prior Лапласа.

## Почему L1 даёт нули — геометрия ⭐
Задача эквивалентна: минимизировать $L(w)$ при $\Omega(w)\le C$. Линии уровня лосса (эллипсы) касаются области ограничений.

```
      w2                             w2
       │    ⬭ эллипсы лосса           │   ⬭
       ◆ ← касание в УГЛУ             │ ╭─●─╮ ← касание на окружности
      ╱│╲   (на оси → w1=0)          │╭╯   ╰╮  (обычно не на оси)
 ────◆─┼─◆──── w1               ─────┼┤  ●  ├──── w1
      ╲│╱                            │╰╮   ╭╯
       ◆                             │ ╰───╯
     L1: ромб                       L2: круг
```
У ромба есть **углы на осях**, и эллипс с большой вероятностью касается именно угла → одна из координат = 0. У круга углов нет.

Ещё объяснение через градиент: штраф L1 тянет вес к 0 с **постоянной силой** $\lambda\,\text{sign}(w)$ даже около нуля, а L2 — с силой $2\lambda w\to0$.

## Elastic Net
$$\Omega = \alpha\|w\|_1 + (1-\alpha)\|w\|_2^2$$
Отбор признаков + устойчивость к коррелированным признакам (выбирает группы).

## Сводка
| | L1 | L2 |
|---|---|---|
| Разреженность | ✅ | ❌ |
| Отбор признаков | ✅ | ❌ |
| Аналитическое решение | ❌ | ✅ |
| Коррелированные признаки | берёт один | делит вес |
| Prior | Laplace | Gauss |
| Робастность к выбросам в весах | выше | ниже |

> [!warning] Масштабирование!
> Перед L1/L2 признаки **обязательно стандартизовать**, иначе штраф неравномерен. Свободный член (bias) **не регуляризуют**.

## Другие виды регуляризации
- **Для деревьев/бустинга**: max_depth, min_samples_leaf, learning rate (shrinkage), subsample, colsample, L1/L2 на листья (XGBoost $\gamma, \lambda$).
- **Для нейросетей** → [[4.7 Регуляризация в DL]]: dropout, weight decay (AdamW), BatchNorm, аугментация, early stopping, label smoothing, mixup.
- **Неявная**: early stopping (≈ L2), SGD шум, ансамбли.
- **Данные**: больше данных — лучшая регуляризация.
