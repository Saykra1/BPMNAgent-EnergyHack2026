# 2.2 Bias-Variance tradeoff и переобучение ⭐⭐⭐

## Разложение ошибки (для MSE)
$$\mathbb E[(y - \hat f(x))^2] = \underbrace{\text{Bias}^2[\hat f]}_{\text{систематическая ошибка}} + \underbrace{\text{Var}[\hat f]}_{\text{разброс от выборки}} + \underbrace{\sigma^2}_{\text{неустранимый шум}}$$

- **Bias (смещение)** — насколько модель в среднем (по всевозможным обучающим выборкам) промахивается. Слишком простая модель → высокий bias → **недообучение**.
- **Variance (разброс)** — насколько предсказания меняются при смене обучающей выборки. Слишком сложная модель → высокая variance → **переобучение**.

```
         Низкий variance      Высокий variance
Низкий   ┌─────────┐          ┌─────────┐
bias     │   ◎●●   │          │ ●  ◎  ● │
         │   ●●    │          │   ●   ● │
         └─────────┘          └─────────┘
            🏆 идеал             переобучение
Высокий  ┌─────────┐          ┌─────────┐
bias     │   ◎     │          │ ●  ◎    │
         │      ●●●│          │    ●  ● │
         │      ●● │          │  ●    ● │
         └─────────┘          └─────────┘
          недообучение          худший случай
```

## Кривая ошибки от сложности модели
```
 Error
   │\                              ╱ test error
   │ \                          ╱
   │  \                      ╱
   │   \____            __╱
   │        `--.____.--'   ← оптимум
   │ \___
   │     `---.___
   │             `----.______ train error
   └──────────────────────────────→ сложность
     underfit   │sweet spot│   overfit
     (bias)                    (variance)
```

## Диагностика
| Симптом | Диагноз | Что делать |
|---|---|---|
| train плохо, val плохо | **Underfitting** (high bias) | усложнить модель, добавить признаки, уменьшить регуляризацию, обучать дольше |
| train отлично, val плохо | **Overfitting** (high variance) | больше данных, регуляризация, упростить модель, early stopping, dropout, аугментация, ансамбли (бэггинг) |
| train ≈ val, оба хорошо | 🏆 | |

**Learning curves** (ошибка vs размер выборки): если кривые train/val сошлись высоко → bias, больше данных не поможет. Если большой зазор → variance, данные помогут.

## Какие модели куда
| Высокий bias | Высокий variance |
|---|---|
| линейная регрессия на нелинейных данных | глубокое дерево без ограничений |
| kNN с большим k | kNN с k=1 |
| сильная регуляризация | полином 15-й степени |

- **Бэггинг / RF** уменьшает **variance** (усредняет некоррелированные глубокие деревья) → [[3.7 Бэггинг и Random Forest]].
- **Бустинг** уменьшает **bias** (последовательно исправляет ошибки простых моделей) → [[3.8 Градиентный бустинг]].

## Double descent (современный взгляд)
У сильно перепараметризованных моделей (нейросети) test error после пика на границе интерполяции **снова падает**. Объясняет, почему огромные нейросети обобщают несмотря на число параметров ≫ данных. Ключ — неявная регуляризация SGD.

```
 test err
   │    /\
   │   /  \
   │  /    \___
   │\/         `----____
   └──────┼─────────────→ #params
     классика │ современный режим
          порог интерполяции
```
