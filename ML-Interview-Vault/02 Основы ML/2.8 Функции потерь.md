# 2.8 Функции потерь (Loss functions)

> Лосс — то, что **оптимизируем** (должен быть дифференцируемым). Метрика — то, чем **оцениваем** (может быть недифференцируемой, например accuracy). См. [[2.5 Метрики классификации]].

## Регрессия
| Лосс | Формула | Свойства |
|---|---|---|
| **MSE** | $\frac1n\sum(y-\hat y)^2$ | штрафует большие ошибки сильно; чувствителен к выбросам; оптимум — **среднее** |
| **MAE** | $\frac1n\sum\lvert y-\hat y\rvert$ | робастен к выбросам; оптимум — **медиана**; негладкий в 0 |
| **Huber** | $\frac12 r^2$ при $\lvert r\rvert\le\delta$, иначе $\delta(\lvert r\rvert-\frac\delta2)$ | MSE возле 0, MAE на хвостах |
| **Log-cosh** | $\sum\log\cosh(r)$ | гладкий аналог Huber |
| **Quantile (pinball)** | $\max(\tau r, (\tau-1)r)$ | оптимум — **квантиль τ**; прогнозные интервалы |
| **MAPE / MSLE** | относительные ошибки | когда важен %, разный масштаб таргета |

```
 loss                    MSE: парабола
  │\        /           MAE: «галочка» V
  │ \      /            Huber: парабола в центре, прямые по краям
  │  \    /
  │   \  /
  │    \/
  └─────────── r = y - ŷ
```

## Классификация
| Лосс | Формула | Где |
|---|---|---|
| **Log-loss / BCE** | $-[y\log p + (1-y)\log(1-p)]$ | [[3.2 Логистическая регрессия]], бинарные сети |
| **Cross-Entropy** | $-\sum_k y_k\log p_k$ | многоклассовая, LLM (next token) |
| **Hinge** | $\max(0, 1 - y\cdot f(x))$, $y\in\{\pm1\}$ | [[3.5 SVM]] |
| **Exponential** | $e^{-y f(x)}$ | AdaBoost |
| **Focal loss** | $-(1-p_t)^\gamma\log p_t$ | дисбаланс, детекция (RetinaNet) |
| **0–1 loss** | $[y \ne \hat y]$ | то, что хотим, но не дифференцируемо |

```
  loss
   │ \  exponential
   │  \\
   │   \ \  log-loss
   │    \ `\
   │ hinge \  `-.__
   │________\______`--.___   margin M = y·f(x)
   │ 0-1 ───┐
   │        └──────────────
   └────────0───1──────────→
```
Все «суррогатные» лоссы — гладкие верхние оценки на 0–1 loss через **отступ (margin)** $M = y\cdot f(x)$: $M>0$ — правильно, $M<0$ — ошибка.

## Метрическое обучение / эмбеддинги
- **Contrastive loss**: тянуть похожие пары, отталкивать непохожие до margin.
- **Triplet loss**: $\max(0, d(a,p) - d(a,n) + m)$.
- **InfoNCE**: $-\log\frac{e^{s(q,k^+)/\tau}}{\sum_j e^{s(q,k_j)/\tau}}$ — CLIP, SimCLR, обучение ретриверов для [[5.15 RAG и агенты|RAG]].

## Специальные
- **KL-дивергенция** — дистилляция, VAE.
- **Dice / IoU loss** — сегментация.
- **CTC** — распознавание речи.
- **Ranking**: pointwise / pairwise (RankNet, BPR) / listwise (LambdaRank, ListNet).

## ❓ Вопросы
- Почему для классификации не используют MSE? С сигмоидой MSE невыпукл по весам и даёт затухающие градиенты при уверенных ошибках ($\sigma'\to0$), а log-loss даёт градиент $p-y$.
- Чем MSE отличается от MAE? Среднее vs медиана, выбросы.
- Как предсказать интервал? Quantile regression с $\tau=0.05$ и $0.95$.
