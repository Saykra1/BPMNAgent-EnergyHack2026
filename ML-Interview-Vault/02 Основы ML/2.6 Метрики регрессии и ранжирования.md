# 2.6 Метрики регрессии и ранжирования

## Регрессия
| Метрика | Формула | Комментарий |
|---|---|---|
| **MSE** | $\frac1n\sum(y-\hat y)^2$ | в квадратах единиц; чувствительна к выбросам |
| **RMSE** | $\sqrt{MSE}$ | в единицах таргета |
| **MAE** | $\frac1n\sum\lvert y-\hat y\rvert$ | робастна |
| **MAPE** | $\frac{100\%}n\sum\frac{\lvert y-\hat y\rvert}{\lvert y\rvert}$ | ломается при $y\approx0$; асимметрична (сильнее штрафует перепрогноз) |
| **SMAPE** | $\frac{100\%}{n}\sum\frac{2\lvert y-\hat y\rvert}{\lvert y\rvert+\lvert\hat y\rvert}$ | симметричный вариант |
| **WAPE** | $\frac{\sum\lvert y-\hat y\rvert}{\sum\lvert y\rvert}$ | популярна в ритейле/прогнозе спроса |
| **R²** | $1-\frac{\sum(y-\hat y)^2}{\sum(y-\bar y)^2}$ | доля объяснённой дисперсии; 1 — идеал, 0 — как среднее, <0 — хуже среднего |
| **Adjusted R²** | $1-(1-R^2)\frac{n-1}{n-d-1}$ | штраф за число признаков |
| **RMSLE** | RMSE на $\log(1+y)$ | относительные ошибки, большие таргеты |

## Ранжирование / рекомендации / поиск
Для каждого запроса/пользователя есть упорядоченный список; важно, чтобы релевантное было **наверху**.

- **Precision@k** = (релевантных в топ-k) / k
- **Recall@k** = (релевантных в топ-k) / (всего релевантных)
- **HitRate@k** = был ли хоть один релевантный в топ-k
- **MRR** = $\frac1{|Q|}\sum\frac{1}{\text{rank}_{\text{первого релевантного}}}$
- **MAP@k** — среднее Average Precision по запросам
- **NDCG@k** ⭐:
$$DCG@k = \sum_{i=1}^k \frac{2^{rel_i}-1}{\log_2(i+1)}, \quad NDCG = \frac{DCG}{IDCG}$$
Учитывает **градуированную** релевантность и позицию (логарифмический дисконт). IDCG — DCG идеального порядка.

```
 позиция:   1     2     3     4     5
 дисконт:  1.0  0.63  0.5  0.43  0.39   (1/log2(i+1))
           ████ ███   ██▌  ██    █▊   ← вклад одинаково релевантного документа
```

- Beyond-accuracy: **coverage**, **diversity**, **novelty**, **serendipity**.

## Бизнес-метрики vs ML-метрики
Оффлайн-метрика (NDCG, AUC) ≠ онлайн-метрика (CTR, конверсия, выручка). Финальная проверка — **A/B-тест** (см. [[1.4 Статистика и MLE]]).

## ❓ Вопросы
- R² может быть отрицательным? Да, если модель хуже константы (на test).
- Чем NDCG лучше Precision@k? Учитывает позицию и степень релевантности.
- Какую метрику выбрать для прогноза спроса? WAPE/MAE (бизнес-интерпретируемо), quantile loss для страховых запасов.
