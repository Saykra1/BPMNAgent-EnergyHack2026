# 1.1 Линейная алгебра

> [!abstract] Зачем в ML
> Данные = матрица $X \in \mathbb{R}^{n \times d}$ (n объектов, d признаков). Модель = набор матриц весов. Предсказание = умножение матриц. Attention = матричные произведения. PCA = SVD.

## Векторы и скалярное произведение
$$\langle a, b \rangle = a^\top b = \sum_i a_i b_i = \|a\|\,\|b\|\cos\theta$$

```
      b
     /
    / θ        a·b > 0  → угол < 90° (похожи)
   /______ a   a·b = 0  → ортогональны
               a·b < 0  → угол > 90° (противоположны)
```
- **Косинусная близость** $\cos\theta = \frac{a^\top b}{\|a\|\|b\|}$ — основа поиска по эмбеддингам, attention (там без нормировки).
- **Нормы**: $L_1 = \sum|x_i|$, $L_2 = \sqrt{\sum x_i^2}$, $L_\infty = \max|x_i|$.

```
  L1 (ромб)      L2 (круг)      L∞ (квадрат)
     /\           .-'-.          +-----+
    /  \         /     \         |     |
    \  /         \     /         |     |
     \/           '-.-'          +-----+
```
Именно форма «шара» объясняет, почему [[2.3 Регуляризация|L1 даёт разреженность]].

## Матрицы
- Умножение $(n\times k)(k\times m) = (n\times m)$. Не коммутативно: $AB \ne BA$.
- Транспонирование: $(AB)^\top = B^\top A^\top$.
- Обратная: $AA^{-1} = I$, существует, если $\det A \ne 0$ (столбцы линейно независимы).
- **Ранг** — число линейно независимых строк/столбцов. Низкоранговые разложения → [[5.10 Fine-tuning и PEFT|LoRA]], [[3.12 Рекомендательные системы|матричная факторизация]].
- Положительно определённая $A \succ 0$: $x^\top A x > 0$ для всех $x\neq0$. Гессиан $\succ0$ ⇒ функция строго выпукла.

## Собственные векторы и значения
$$A v = \lambda v$$
Матрица просто **растягивает** вектор $v$ в $\lambda$ раз, не поворачивая.
- Для симметричной $A$: $A = Q\Lambda Q^\top$, $Q$ ортогональна (собственные векторы ортогональны).
- Ковариационная матрица симметрична → её собственные векторы = **главные компоненты** ([[3.10 Понижение размерности|PCA]]).

## SVD — сингулярное разложение (любая матрица!)
$$X = U \Sigma V^\top$$
```
 X (n×d)  =  U (n×n)  ·  Σ (n×d, диагональ σ1≥σ2≥…≥0)  ·  Vᵀ (d×d)
            «поворот»     «растяжение по осям»              «поворот»
```
- Усечённое SVD (оставить k наибольших σ) — **наилучшее приближение ранга k** (теорема Эккарта–Янга).
- Применения: PCA, LSA (тематическое моделирование), рекомендации, сжатие, псевдообратная матрица $X^+ = V\Sigma^{+}U^\top$.

## Полезные факты для ML
| Факт | Где используется |
|---|---|
| $\nabla_w (w^\top A w) = (A + A^\top)w$ | вывод МНК |
| $\nabla_w \|Xw - y\|^2 = 2X^\top(Xw - y)$ | [[3.1 Линейная регрессия]] |
| $X^\top X$ — симметричная, PSD | нормальное уравнение, ковариация |
| След: $\mathrm{tr}(AB)=\mathrm{tr}(BA)$ | матричные производные |
| Число обусловленности $\kappa = \sigma_{max}/\sigma_{min}$ | мультиколлинеарность, плохая сходимость GD |

## ❓ Вопросы на собеседовании
- **Что такое собственный вектор?** Направление, которое матрица только масштабирует.
- **Чем SVD отличается от собственного разложения?** SVD существует для любой прямоугольной матрицы; eigendecomposition — только для квадратных (и не всегда диагонализуемых). $X^\top X = V\Sigma^2V^\top$ — связь между ними.
- **Почему $X^\top X$ может быть необратима?** Мультиколлинеарность / $d > n$ → лечится L2-регуляризацией ($X^\top X + \lambda I$ всегда обратима).
