# 1.3 Теория вероятностей

## Базовые понятия
- **Условная вероятность**: $P(A|B) = \frac{P(A\cap B)}{P(B)}$
- **Независимость**: $P(A\cap B) = P(A)P(B)$
- **Формула полной вероятности**: $P(A) = \sum_i P(A|B_i)P(B_i)$

## Теорема Байеса ⭐
$$\underbrace{P(\theta|D)}_{\text{posterior}} = \frac{\overbrace{P(D|\theta)}^{\text{likelihood}}\;\overbrace{P(\theta)}^{\text{prior}}}{\underbrace{P(D)}_{\text{evidence}}}$$

> [!example] Классическая задача
> Болезнь у 1% людей. Тест: чувствительность 99%, ложноположительные 5%. Тест положительный — вероятность болезни?
> $P(D|+) = \frac{0.99\cdot0.01}{0.99\cdot0.01 + 0.05\cdot0.99} \approx 0.167$ — всего **17%**! (Base rate fallacy — связано с [[3.14 Дисбаланс классов|дисбалансом]] и precision.)

## Матожидание, дисперсия, ковариация
- $\mathbb{E}[X] = \sum x\,p(x)$; линейно: $\mathbb{E}[aX+bY] = a\mathbb{E}X + b\mathbb{E}Y$
- $\mathrm{Var}(X) = \mathbb{E}[(X-\mathbb{E}X)^2] = \mathbb{E}X^2 - (\mathbb{E}X)^2$
- $\mathrm{Var}(aX) = a^2\mathrm{Var}X$; для независимых $\mathrm{Var}(X+Y)=\mathrm{Var}X+\mathrm{Var}Y$
- $\mathrm{Cov}(X,Y) = \mathbb{E}[XY]-\mathbb{E}X\mathbb{E}Y$; корреляция Пирсона $\rho = \frac{\mathrm{Cov}}{\sigma_X\sigma_Y}\in[-1,1]$ — только **линейная** связь.
- Среднее $n$ независимых величин: $\mathrm{Var}(\bar X) = \sigma^2/n$ — **почему работает бэггинг** (см. [[3.7 Бэггинг и Random Forest]]). Если корреляция $\rho$: $\rho\sigma^2 + \frac{1-\rho}{n}\sigma^2$.

## Основные распределения
| Распределение | Где | Параметры | Среднее / дисперсия |
|---|---|---|---|
| Бернулли | бинарная классификация | $p$ | $p$ / $p(1-p)$ |
| Биномиальное | число успехов в n испытаниях | $n,p$ | $np$ / $np(1-p)$ |
| Категориальное | многоклассовая (softmax) | $p_1..p_K$ | |
| Пуассон | счётчики событий | $\lambda$ | $\lambda$ / $\lambda$ |
| Равномерное | инициализация | $a,b$ | $\frac{a+b}2$ / $\frac{(b-a)^2}{12}$ |
| Нормальное | шум, MSE, VAE | $\mu,\sigma^2$ | $\mu$ / $\sigma^2$ |
| Экспоненциальное | время ожидания | $\lambda$ | $1/\lambda$ / $1/\lambda^2$ |
| Бета / Дирихле | априорные для $p$ (Thompson sampling, LDA) | | |

```
 Нормальное: 68% в ±1σ, 95% в ±2σ, 99.7% в ±3σ (правило трёх сигм → выбросы)
        ___
      /     \
    /    |    \

   -2σ -σ μ +σ +2σ
```

## Предельные теоремы
- **ЗБЧ**: выборочное среднее → матожидание.
- **ЦПТ**: сумма/среднее многих независимых величин ≈ нормальное. Основа доверительных интервалов и A/B-тестов.

## Энтропия и KL ⭐ (очень важно для DL)
- **Энтропия**: $H(p) = -\sum p\log p$ — мера неопределённости.
- **Кросс-энтропия**: $H(p,q) = -\sum p\log q$ → это и есть [[2.8 Функции потерь|CE loss]].
- **KL-дивергенция**: $D_{KL}(p\|q) = \sum p\log\frac{p}{q} = H(p,q) - H(p) \ge 0$; несимметрична.
- Минимизация CE ≡ минимизация KL (т.к. $H(p)$ константа) ≡ MLE.
- Где KL: VAE, дистилляция, RLHF (штраф за отклонение от reference-модели), t-SNE.
