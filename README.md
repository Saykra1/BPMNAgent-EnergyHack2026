# Команды, приглашения и роли

Несколько аналитиков работают с одной BPMN-схемой. Владелец создаёт команду, приглашает людей ссылкой и назначает, кто может править схему, а кто только смотреть.

Генерация диаграммы из текста по-прежнему работает без входа. Команда нужна, чтобы сохранить схему и открыть её у другого участника.

## Запуск

Из корня репозитория, Python 3.10+:

```powershell
.\run.bat
```

Сервер: http://127.0.0.1:8080

Ключ LLM для этой фичи не нужен. Схему можно взять из примера: «Показать сохранённый результат примера», затем сохранить в проект команды.

Данные команд лежат в `data/collab.db`. Этот файл не коммитится.

## Как проверить вдвоём

Нужны два разных окна: обычное и инкогнито. Два обычных окна — это один и тот же человек, токен хранится в браузере.

1. В первом окне нажмите «Команда», назовите себя и создайте команду. Вы становитесь владельцем.
2. Создайте проект, откройте его, постройте или загрузите схему и нажмите «Сохранить». На тулбаре будет «версия N, сохранил …».
3. Создайте ссылку с ролью «Редактор» и скопируйте её.
4. Откройте ссылку во втором окне и введите другое имя.
5. Откройте тот же проект и нажмите «Загрузить последнюю версию». Появятся текст и схема из первого окна.
6. Измените описание во втором окне, сохраните. В первом окне загрузите последнюю версию.
7. Если сохранить поверх уже обновлённой схемы, сервер откажется и попросит сначала загрузить свежую копию.

Живой ленты нет: чужие правки видны только после «Сохранить» у одного и «Загрузить последнюю версию» у другого.

## Роли

| Роль | Что может |
|---|---|
| Владелец | Приглашения, смена ролей, исключение участников, удаление проектов, правка и сохранение |
| Редактор | Новые проекты, правка холста, генерация, сохранение |
| Наблюдатель | Открыть схему и скачать `.bpmn`, SVG, PNG. Генерация, диалог и сохранение закрыты |

Ссылка приглашения действует, пока владелец её не отзовёт. Роль задаётся в момент создания ссылки. По умолчанию приглашённый — редактор. Повторный переход по другой ссылке не повышает уже выданную роль.

Владельцев может быть несколько. Последнего владельца нельзя понизить и нельзя исключить.

Чтобы проверить наблюдателя: владелец меняет роль второго участника на «Наблюдатель», тот заново открывает проект. Кнопки «Сохранить» и «Сгенерировать» недоступны.

## Автотесты

```powershell
python -m pytest backend/tests/test_collab.py -q
```

Проверяются приглашение, сохранение редактором, отказ наблюдателю, недоступность чужой команды, конфликт версий и запрет убрать последнего владельца.

## Ограничения

- Пароля и почты нет. Кто открыл ссылку и назвал себя, тот вошёл.
- Одновременная правка одного блока не сливается. Сохраняется только та версия, которую открыли последней загрузкой.
- Удалять проект может только владелец.
