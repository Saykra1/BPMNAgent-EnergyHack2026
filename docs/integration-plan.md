# Интеграция веток `makar` и `features_from_tyoma`

Основа: `stepa_1`. Работа ведётся в отдельной ветке `integration_makar_tyoma`; прежняя версия не меняется.

1. Из `makar` перенести аккаунты, команды, приглашения, роли и общие проекты с версионным сохранением. Подключить их отдельным API и компактной панелью. Проверку разрешённых изменений адаптировать к существующему BPMN XML, без зависимости от нового конвейера `makar`.
2. Из `features_from_tyoma` перенести локальное обнаружение персональных данных Natasha, ручную маскировку и предпросмотр «что увидит модель». Маскировать все обращения к генератору на границе LLM-клиента и восстанавливать метки в ответах; существующие режимы, Jev и построение BPMN не менять.
3. Проверить регистрацию двух пользователей, приглашение, права, конфликт версий, открытие/сохранение схемы, маскировку на реальном вызове тестовой модели и основные сценарии интерфейса. Затем обновить README и отправить интеграционную ветку.

Другие изменения веток (новый IR-компилятор, исполнение процессов, автогенерация документов, разрешение противоречий через отдельные LLM-вызовы) затрагивают ядро построения и не входят в эту интеграцию. Их можно переносить отдельно после проверки совместимости.
